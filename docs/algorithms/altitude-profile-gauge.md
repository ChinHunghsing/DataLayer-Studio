# 海拔剖面 Gauge

## 语义

- 横轴是累计距离，不是运动时间；暂停期间距离保持，因此光标与已完成区域都不前进。
- 纵轴是实时海拔。COROS 文件继续使用厂商识别后的显示平滑海拔；累计爬升不参与本 Gauge。
- 当前帧没有有效距离，或全程不足两个有效“距离 + 海拔”点时，整个 Gauge 保持透明，不回退到时间轴。

## 几何预计算

`AltitudeProfileGeometry` 在 `OverlayRenderer` 创建时构建一次：

1. 丢弃非有限值、负距离和倒退距离。
2. 相同距离只保留最后一个海拔点，折叠暂停期间的重复距离。
3. 总距离取活动末距离与最后有效剖面距离的较大值；若剖面提前结束，以末海拔延伸到总距离。
4. 少于两个点时不可见；超过 4096 点时确定性降采样并保留首尾点。

## 渲染

- 未完成曲线显示全程轮廓；已完成曲线、填充和光标由当前距离裁切。
- 实时海拔优先取当前遥测样本，缺失时按距离在剖面内插值。
- 默认最小可视海拔范围为 50 米，纵向留白为 12%。
- 默认网格为 3 行、4 列；距离标签使用 KM，海拔标签使用 M。
- 宽度与高度可独立缩放，文字、线宽和光标按两者较小值缩放，避免单轴拉伸导致内容失真。
