## 0. 现状摘要

iPad 版已经从提案进入可用实现。当前在 iPad 模拟器上可以完整走通核心闭环：

**导入视频 + FIT/GPX → 三种对表方式 → 画布触控排布 21 种数据组件 → 实时预览 → 导出合成成片（HEVC/H.264，保留原视频音轨）**

界面为与 Mac 版同心智的三栏编辑器（素材/导出 | 预览画布+时间轴 | 检查器），regular 宽度三栏常驻、compact 宽度画布优先 + sheet；四语言（en / zh-Hans / zh-Hant / ja）文案齐备；布局预设与 Mac 版走同一 iCloud Key-Value 机制。

## 1. 产品定位（2026-07-06 修订）

一句话：**把「同步 → 排布 → 导出成片」的完整工作流带到 iPad，跑完当天在 iPad 上直接出片。**

**已定决策：iPad 版只导出最终成片（合成 HEVC/H.264 视频），不提供透明浮层导出（HEVC-alpha / ProRes 4444）。** 移动设备用户要的是可直接分享的成片；透明浮层这种进专业剪辑软件的中间产物，其供给完全由 Mac 版承担。该决策同样适用于未来的 iPhone 形态（同一 iOS App）。

三端分工：

| | Mac | iPad | iPhone（未开工） |
| --- | --- | --- | --- |
| 编辑深度 | 全量 | 对齐 Mac（v1 为核心子集，持续补齐） | 轻编辑、模板优先 |
| 主要产物 | 透明浮层 + 成片 | **仅成片** | **仅成片** |
| 预设角色 | 生产端 | 生产端 + 消费端 | 消费端 |
| 商业模式 | 买断（现状不动） | 订阅（月 $1.99 / 年 $19.99，试用 7 天；免费层可编辑预览，导出需订阅） | 同 iPad（同一 App 同一订阅） |

品牌与视觉：延续「专业、克制、可信」的深色编辑器气质，原生 iPadOS 控件优先。

### 非目标（维持不做）

- 透明浮层导出（已定决策，见上）。
- CLI / 快捷指令自动化（远期）。
- HealthKit / Apple Watch 直接导入（远期）。
- 外接显示器专业双屏模式。

## 4. 界面与交互现状

- **三栏布局**：左栏（素材卡片 → 对表 → 布局预设 → 导出）340pt；中间画布 + 时间轴 + 状态栏；右栏检查器 340pt。左右栏可由工具栏折叠；compact 宽度（竖屏/分屏）时两栏转为 sheet。
- **画布**：视频 aspect-fit + 浮层图实时叠加；单指点选/拖动组件，点空白取消选中；空状态给引导文案。
- **时间轴**：播放/暂停（空格）、逐帧步进、scrub 滑杆、当前/总时长显示；播放范围钳到导出区间。
- **检查器**：添加组件菜单（按数据可用性禁用）+ 选中组件设置子集（见 §3 表）。
- **导出**：无模式切换（只有成片）；编码 HEVC/H.264；导出中锁定编辑、屏幕常亮、显示「导出期间请保持 App 在前台」；完成出结果卡片（分享 / 存入照片 / 用时）。
- **键盘快捷键**（已接）：⌘O 选视频、⌘F 选活动文件、⌘E 导出、⌘. 取消、空格播放/暂停、⇧⌘S 打点、⌘Z/⇧⌘Z 撤销重做。方向键微调、⌥⌘↑↓ 层级、⌘± 缩放未接。

## 6. 成功指标（维持不变）

激活（同时导入视频与活动文件）≥ 60%；首次完成导出中位耗时 ≤ 10 分钟；导出成功率 ≥ 99%；崩溃率 < 0.3% 会话；预设跨设备使用跟踪基线。

## 7. 后续工作建议（按优先级）

1. **真机验证**（下一步首选）：真机跑合成 HEVC 硬编导出，记录性能/热基准；手测导出中退后台/来电中断路径。
2. **检查器补齐**：向 Mac 版对齐深度定制项（字体、颜色、刻度、线宽、标签/单位覆盖），顺带接运动数据裁切 UI。这是「能力对齐」定位的主要缺口。
3. **M3 平台特性**：拖拽导入、多窗口、键盘全键位、Pencil/指针悬停、画布捏合缩放与网格吸附。
4. **发布前置**：订阅门与 Paywall（独立 App record + StoreKit 2，方案见 `docs/mobile-subscription-design.md`）、隐私清单、正式 Xcode 壳工程、天气、无障碍与四语言验收（工程细节见技术文档 §8）。
5. **架构收敛**（与功能并行规划）：把 iPad 会话模型与 Mac StudioModel 的重复编排逐步下沉到 OverlayStudioKit（见技术文档 §2）。
