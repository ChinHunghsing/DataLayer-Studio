## 1. 评审结论：现状诊断（按严重度排序)

以下问题基于当前代码逐文件核对，附定位。

### S1 · 严重：范式撕裂 —— 向导隐喻叠在 NLE 骨架上

- `SidebarView.swift:14-33`：左栏仍是「步骤 1 素材 → 步骤 2 画布」的向导编号。这是单素材时代的遗产；0.2.3 已经是多轨时间线编辑器，用户操作根本不是线性的，编号只制造「我必须按顺序做」的错误心智。
- `StudioModel` 仍保留「活跃视频素材 / 活跃活动素材」（`activeVideoAssetID`）概念，与时间线「片段才是事实」的权威模型并存。素材池里一份素材同时有「选中 / 活跃 / 在时间线使用中」三种状态，用户无法区分。该状态还参与旧工程恢复、对表和素材生命周期，0.3.0 不能直接删除模型字段。
- 结论：**左栏的定位必须重写**——它应该是「库」（素材、组件、模板），不是「向导 + 杂项设置」；0.3.0 先从 UI 移除「活跃」表达，底层兼容清理另行立项。

### S2 · 严重：23 种数据组件没有可见入口

- 添加 gauge 的唯一入口是检查器头部的 `+` 下拉菜单（`InspectorSelectionHeader.swift:114`），一个纯文字长列表。
- 这是本产品的**核心资产**（22 种遥测组件 + 天气/路线/时间），却被藏在三级深的菜单里；新用户完全无法浏览「我能加什么」。竞品（Telemetry Overlay、Garmin 官方）都把组件库做成可视化图库。
- 结论：组件库必须成为一等公民面板，带渲染预览、搜索、拖放上画布。

### S3 · 高：检查器过载，编辑路径太深

- `InspectorSettingsPanel.swift` 2016 行，五分段（布局/内容/外观/字体/数据）× 折叠组 × 「标签/数值/单位/图标」四部件矩阵（`InspectorSettingsPanel.swift:728-790` 的巨型 case 表）。
- 改一个数值字号的路径：选中元素 → 切「字体」分段 → 展开折叠组 → 在四部件 Picker 里选「数值」→ 调字号。四步深，且「部件」这个抽象概念用户在画布上看不见。
- 位置/大小用滑杆 + 裸数值混排（X=201、Y=17.901 单位制不一致），精调体验差。
- 结论：检查器需要「常用恒显 + 高级渐进披露」重构，部件选择应搬到画布上（点选即编辑）。

### S4 · 高：双时间轴冗余

- 预览控制条里有一条 `PreviewTimelineSlider`（限制在导出区间内），底部又有权威时间线 `ProjectTimelineView` 的播放头；两条时间轴显示同一播放位置，导出范围也有两套控制（`ExportTrimRangeControl` + 时间线 `exportRangeLayer`，`ProjectTimelineView.swift:838`）。
- 结论：**只留一条时间轴**。预览控制条只保留 transport（播放/逐帧/时间码）；导出范围统一为时间线 In/Out 点（I/O 快捷键，行业标准）。

### S5 · 高：启动入口仍被模态承载

- 空项目启动仍弹 `StartupSourcePromptView` 模态；0.2.3 已加入「打开现有工程」并重做布局，但最近工程仍只在菜单栏，首屏不能浏览历史工程、模板或拖放入口。
- 结论：改为**欢迎窗口**：最近工程列表 + 新建/打开工程 + 用户模板 + 整窗拖放导入。0.3.0 不引入工程内嵌缩略图、内置模板或示例工程下载，先把首屏路径做完整。

### S6 · 中：手动网格配置是伪需求

- 左栏让用户配置 21×64 的行列数网格再开吸附（`SidebarView.swift:122-146`）。没有用户想「设定 30 行网格」；他们想要的是「拖动时自动对齐别的元素和安全边距」。
- 结论：删除行列配置，改为 Keynote 式**智能参考线**（元素边缘/中心互相吸附、画布中线、可配置安全框），网格仅保留开关。

### S7 · 中：导出体验分散

- 入口在标题栏 accessory 按钮（`OutputToolbarAccessory`）、设置在弹出面板（`OutputPanelView` 的 picture/encoding 卡片）、进度在另一个 sheet（`ExportStatusSheet`）、裁剪又在时间线。
- 分辨率/帧率/码率/编码 每次导出都要重复确认，没有「导出预设」概念。
- 结论：统一为**导出中心**（⌘E 唤起单一 sheet）：左侧命名预设（透明浮层·ProRes / YouTube 4K / 竖屏社媒 / 自定义…），右侧摘要与覆盖项，进度就地显示。

### S8 · 中：状态通信原始

- 全局状态是左栏页脚一行 `model.status` 文本（`SidebarView.swift:46`），瞬时消息（「已保存」）与持久状态（「运动开始已设置在 50 秒」）混在同一条里互相覆盖。0.2.3-D 已承认此债（toast 通道）。
- 结论：瞬时消息走 toast（自动消失、可堆叠），持久状态就地显示（同步状态放时间线片段角标、导出状态放导出中心），删除页脚状态行。

### S9 · 中：面板刚性

- 左 330pt / 右 390pt 固定宽度不可调、不可折叠（`ContentView.swift:145-163`）；最小窗口 1320×760。全屏预览是独立模式切换而非面板收纳。
- 结论：三面板可拖拽调宽、可一键折叠（⌥⌘1 库 / ⌥⌘2 时间线 / ⌥⌘3 检查器，对齐 FCP 习惯）。0.3.0 保留现有全屏预览行为，待折叠状态与缩放、退出快捷键完全等价后再合并实现。

### S10 · 低：预设（模板）是文字列表

- 布局预设是「文本框起名 + 图标按钮保存 + 文字行列表」（`SidebarView.swift:148-205`），无缩略图、无内置模板。对「快速出片」这个核心卖点来说，模板应该是可视化的。

## 2. 设计原则（重构北极星）

1. **一条主线**：新用户的完整旅程是「拖进来 → 自动对表 → 挑个模板 → 导出」，四步全部在首屏可见，零菜单探索。
2. **画布即编辑器**：能在画布上直接完成的（选部件、对齐、微调），不进检查器；检查器只做画布表达不了的属性。
3. **一个事实源**：时间线是时间的唯一事实源；素材池只是仓库；UI 不再暴露「活跃素材」，底层暂时保留旧工程兼容字段。
4. **库在左、属性在右、时间在下**：与 FCP/DaVinci/Motion 一致的空间记忆，不发明新布局。
5. **默认智能，手动兜底**：自动对表、智能参考线、导出预设是默认路径；手动偏移、网格、自定义参数保留为高级路径。

## 4. 分模块详细方案

### 4.1 欢迎窗口（新增 `WelcomeWindowView`）

- 单例辅助 window scene：左侧「新建工程 / 打开工程」，右侧最近工程列表；打开或新建后复用现有主编辑窗口，不扩展为多工程并行编辑。
- 最近工程行显示工程名、最后打开时间和路径摘要；0.3.0 使用统一文档图标，不修改单文件 JSON 格式的 `.dlsproj`。如后续确需缩略图，只允许放在 Application Support 派生缓存中，可随时重建，不写入工程文件。
- 底部横排用户模板，点击即「新建工程 + 应用模板」；不提供内置模板。
- 整窗接受拖放：视频/FIT/GPX/工程文件，拖入即建工程并自动对表。
- 有工程打开时不自动显示；「窗口 ▸ 欢迎窗口」可召回。删除 `StartupSourcePromptView`。两个 source-continuation alert 仅在素材库空状态与「补充配套素材」内联入口覆盖完整后删除，避免单素材用户失去下一步提示。

### 4.2 库面板（重写 `SidebarView` → `LibraryPanelView`）

- 顶部分段：**素材 · 组件 · 模板**。
- 素材：现 `MediaPoolList` 保留（在用/离线/relink 状态已完善），UI 删除「活跃」徽标与切换操作——预览跟随时间线播放头，不跟随素材选中；点选素材只做高亮与检查器显示元信息。底层 `activeVideoAssetID` / `activeActivityAssetID` 在 0.3.0 保留，避免破坏旧工程和对表逻辑。
- 组件：网格图库，覆盖当前 23 种组件；按「指标块 / 仪表盘 / 地图·进度 / 信息块」分组；顶部搜索框；拖到画布落点即添加，双击加到默认位置。0.3.0 使用预生成静态缩略图，不在主线程实时调用渲染器，也不改 `OverlayCore` 快照/并发路径。
- 模板：布局预设升级为缩略图卡片，使用 `OverlayLayout` 绘制轻量位置示意，不调用渲染器；保留保存、默认、删除、导入、导出与 iCloud 同步状态。模板全部由用户创建或导入。
- 网格行列 stepper、吸附开关从左栏删除（见 4.3）。

### 4.3 画布操控（改 `PreviewCanvasView`）

- **智能参考线**：拖动元素时对齐其他元素边缘/中心、画布中线/三分线、安全框（内缩百分比可在设置中调），吸附时显示黄色参考线并轻微磁吸。替换现有网格吸附；`showGrid` 保留为纯视觉开关（视图菜单）。
- **部件子选择**:单击选元素，再单击选中元素内部件（标签/数值/单位/图标），画布上部件高亮，检查器自动切到该部件的字体/颜色。Esc 逐级退出。检查器里的部件 Picker 矩阵随之删除。
- 多选（⇧点选/框选）+ 对齐分布命令（左/右/顶/底/水平居中/垂直居中/等距），进「排列」菜单与右键菜单。
- 右键菜单补全：复制样式/粘贴样式、置于顶层/底层、删除。
- transport 条精简：播放/暂停、逐帧、时间码输入（`TimecodeField` 保留）、缩放/适配控件；删除 `PreviewTimelineSlider`。

### 4.4 检查器重构（重写 `InspectorSettingsPanel` 的组织层）

- **快速控件区**（恒显，不折叠）：X/Y/宽/高数值字段（统一像素单位、可拖拽划动改值）、不透明度、显示/隐藏。删除滑杆+裸数值混排。
- 分段从五个减为三个：**内容**（该组件显示什么：标签文案、单位制、图标选择）、**样式**（面板底色/圆角/描边、字体——作用于当前画布选中的部件）、**数据**（精度、仪表 min/max、天气 key、平滑）。原「布局」分段被快速控件区吸收，「外观+字体」合并为「样式」（随画布部件选择联动）。
- 折叠状态记忆保留（`@SceneStorage` 机制沿用）。
- 时间线片段检查器（`TimelineClipInspectorView`）保持现结构，仅套用新视觉令牌。

### 4.5 时间线与对表（改 `ProjectTimelineView` + `BottomWorkspaceView`）

- ~~唯一时间轴：导出范围 = In/Out 点（快捷键 I/O 设置、⌥X 清除），替换 `ExportTrimRangeControl`；范围高亮样式沿用 `exportRangeLayer`。~~（已废弃：出入点范围功能已于 0.3.0 期间整体移除 af4380e，导出恒为完整时间线，不再引入 I/O 快捷键。）
- **对表可视化**：自动对表完成后，在视频片段与活动片段之间画对齐标记（同刻竖线 + 「已按拍摄时间对表」角标）；拖动活动片段 = 手动微调偏移，按住 ⌥ 出现 ±毫秒微调字段。~~原「同步模式」三选一收进片段检查器的「高级对表」折叠组。~~（已过时：「同步模式」三选一 UI 早已整体移除，现片段检查器折叠组只含偏移字段与「重新自动对表」入口。）
- `⌘⇧S` 已属于工程另存为；0.3.0 移除「标记运动开始」的重复快捷键，保留菜单命令，后续仅在完整快捷键审计后再分配新组合。
- 头部工具行精简：轨道显隐、锁定继续常驻；添加、删除、重命名等低频操作收进菜单；保留缩放控件。手动“重新自动对表”推迟到 0.3.2。

### 4.6 工具栏与窗口（改 `StudioWindowView`）

- 用真正的 NSToolbar（`.toolbar` API）替换 `TitlebarTrailingAccessory` 私有注入：左侧面板开关三连（库/时间线/检查器，⌥⌘1/2/3），中间标题（工程名·未保存点），右侧「导出 ⌘E」。
- 三栏改 `HSplitView`（或自绘可拖分栏），左 260–420、右 320–480 可调，可折叠；`bottomResizeHandle` 机制保留。0.3.0 保留独立 fullscreen 模式分支，统一实现推迟到折叠状态的缩放、焦点、快捷键和退出行为验收等价之后。
- 最小窗口降到 1100×700（面板可折叠后成立）。

### 4.7 导出中心（重写 `OutputPanelView` + `ExportStatusSheet` 合一）

- ⌘E 唤起单一 sheet：左列**导出预设**（内置：透明浮层·ProRes 4444 / 透明浮层·HEVC / 成片·4K HEVC / 成片·1080p H.264 / 竖屏 4K；用户可另存自定义预设），右侧当前预设的参数与覆盖项 + 摘要（沿用 `ExportSummaryCard` 数据）+ 目标位置。
- 点导出后 sheet 就地切换为进度视图（进度/ETA/取消沿用现逻辑），完成态就地显示结果与「访达中显示/打开」。三个 sheet 合为一个。
- 预设为新增 Codable 存储，走 `StudioPreferenceStore`，向后兼容零风险（新文件）。不加入 CLI 等效命令提示；该项已在 0.2.3 明确放弃，除非后续重新授权。

### 4.8 状态系统

- 新增 toast 层（画布右下角，自动 3s 消失，可堆叠 3 条）：保存成功、预设应用、自动对表结果、复制完成等瞬时消息。（实现偏差：toast 实际挂载于整窗右下角与导出 sheet 右下角，非画布右下角。）
- 持久状态就地化:同步状态→时间线片段角标；离线素材→素材池行（已有）；导出→导出中心。删除左栏页脚 `statusFooter`。
- `model.status` 字符串通道保留为 debug console 日志源，不再上屏。（实现偏差：「不再上屏」已完成，但 `setStatus` 未接入 debug console；未升级为 toast 的瞬时消息目前没有任何用户可见出口，遗留至 0.3.3。）

### 4.9 视觉令牌收敛

- `ShellStyle` 扩展为完整令牌集：三级表面（面板/分组/控件）、两级描边、四级字号（11/12/13/15）、4pt 基础间距序列（4/8/12/16/24/32）、统一圆角（6/8/10）。
- 全局 `controlSize(.small)` 改为分层：快速控件区 .regular，高级折叠区 .small。
- 数字字段统一组件（现 `NumberField`/`InlineIntField`/`CompactNumberIntField` 三套合一），支持拖拽划动改值；禁千分位逗号（既有约定）。

## 5. 实施路线（三个版本，每步独立可发布）

## 8. 0.3.0 设计简报（已确认范围）

### 功能摘要

0.3.0 面向需要长时间、高频整理素材、对表和导出的桌面创作者，重做 DataLayer Studio 的编辑器外壳。目标不是增加渲染能力，而是让新用户能从欢迎窗口进入清晰主路径，让熟练用户获得稳定、紧凑、可调的 NLE 工作区。

### 首要用户动作

用户进入 App 后，应能立即新建或打开工程；进入编辑器后，应能在左侧库中找到素材、组件和模板，并明确底部时间线是唯一时间事实源。

### 设计方向

- 专业、紧凑、克制，沿用 Final Cut Pro / Premiere 类非线性编辑器的空间记忆。
- 高频操作常驻，低频操作进入菜单或渐进披露；不使用大标题、卡片堆叠、装饰阴影和过量胶囊按钮。
- 使用系统语义色、系统控件和 4pt 间距节奏，保持明暗主题、键盘、鼠标和辅助功能一致。

### 布局策略

- 欢迎窗口只负责进入工程，不承担编辑器功能。
- 编辑器保持「库在左、画布居中、检查器在右、时间线在下」；左右栏可调宽和折叠，时间线高度沿用现有拖拽机制。
- Toolbar 只放面板开关、工程标题和导出等全局命令；轨道状态留在对应轨道，属性编辑留在检查器。

### 关键状态

- 首次启动：无最近工程，突出新建、打开和拖放，并给出最短说明。
- 有最近工程：按最近打开排序；文件失效时显示不可用状态并允许从列表移除或重新定位。
- 空工程：素材 tab 提供视频/FIT/GPX 拖放和选择入口，组件与模板仍可浏览。
- 单素材工程：以内联提示补充配套素材，不弹连续模态。
- 正常编辑：播放头驱动预览；素材选中只显示元信息，不改变播放源。
- 窄窗口：面板可折叠，1100×700 仍能完成导入、编辑和导出主路径。
- 全屏预览：0.3.0 延续既有行为，不因新面板状态造成焦点或缩放回退。

### 交互模型

- 欢迎窗口支持点击与拖放；打开工程后窗口自动隐藏，主编辑窗口获得焦点。
- Library tab 切换不改变时间线选择；组件可双击添加或拖到画布，模板应用后给出明确反馈。
- 面板折叠支持 Toolbar、菜单和快捷键三条等价路径，状态在窗口会话内恢复。
- I/O 与 ⌥X 操作同一份导出范围数据；删除预览滑杆后，Space、逐帧和时间码输入仍作用于底部时间线播放头。

### 文案需求

- 四语言新增：欢迎窗口、最近工程空/失效状态、Library 三 tab、组件分类与搜索、用户模板空状态、面板菜单、In/Out 命令、单素材内联提示。
- 文案保持动作导向，避免重复标题；错误状态必须说明用户下一步能做什么。

### 实施时重点参考

- `spatial-design.md`：四区工作区、可调面板和窄窗口降级。
- `interaction-design.md`：拖放、焦点、快捷键、面板状态反馈。
- `ux-writing.md`：欢迎页空状态、失效工程和单素材引导。
- `color-and-contrast.md`：系统语义色、轨道状态和明暗主题对比度。

### 已决策事项

- 0.3.0 不做工程内嵌缩略图、不删 active 模型、不重写检查器、不合并导出中心、不删除独立全屏模式。
- `⌘⇧S` 专用于另存为；「标记运动开始」暂不设默认快捷键。
- 组件缩略图使用预生成静态资源，避免触碰渲染并发风险。
- 模板全部由用户创建或导入；手动“重新自动对表”按钮推迟到 0.3.2。
