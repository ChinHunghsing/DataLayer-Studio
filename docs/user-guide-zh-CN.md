# DataLayer Studio 功能说明与使用手册

最后更新：2026-07-11

适用版本：macOS 0.2.2 及当前 `main` 分支

DataLayer Studio 是一款面向跑步、骑行和户外运动视频的数据浮层制作工具。它把视频素材与 `.fit` / `.gpx` 运动记录放进同一条多轨时间线，在实时预览中排布速度、配速、心率、路线、距离、天气等组件，最后输出透明浮层或已经合成好的视频。

这份文档分为三部分：

1. 功能说明：先了解软件能做什么、不能做什么。
2. 使用手册：从新建工程到导出的完整操作流程。
3. 实战案例：用常见拍摄场景说明怎样组织和对齐复杂时间线。

## 1. 软件适合做什么

典型用途包括：

- 为比赛回顾视频叠加路线、距离、配速和心率。
- 为训练复盘视频展示步频、功率、跑姿和海拔数据。
- 把一整次运动中分散拍摄的多个视频片段放回正确的运动时间。
- 输出透明 Alpha 浮层，交给 DaVinci Resolve、Final Cut Pro 或 Premiere 继续剪辑。
- 直接输出带原视频、原声音和数据浮层的成片。
- 保存工程和布局预设，在下一条视频中继续使用。

DataLayer Studio 遵循“剪辑逻辑标准、交互保持轻量”的原则。时间线支持多视频轨、多运动数据轨、片段移动、裁剪、分割、多选、吸附、锁轨和撤销，但当前不是完整的非线性剪辑软件：

- 暂不包含转场、变速、画中画、关键帧和多机位切换工具。
- 视频轨重叠时，上层视频整画面覆盖下层视频。
- 运动数据轨用于叠加数据组件，不用于混合两个视频画面。

## 2. 核心功能一览

### 2.1 素材与工程

- 导入一个或多个视频文件。
- 导入一个或多个 `.fit` / `.gpx` 运动文件。
- Finder 多选导入时，所选素材会按顺序自动加入时间线。
- 时间线已有内容时，新导入素材默认从工程末尾继续追加。
- 媒体池会标记哪些素材“使用中”，离线素材可重新链接。
- 时间线工程保存为 JSON，包含素材引用、轨道、片段位置、布局和输出设置。

### 2.2 标准多轨时间线

- 视频轨与运动数据轨都可以有多条。
- 片段可自由移动，时间线开头、片段之间和结尾都允许留白。
- 视频和运动片段可在同类轨道之间移动。
- 片段两端可裁剪；裁剪会改变素材入点或出点。
- 片段头尾可吸附时间线起点、红色播放头和其他片段边缘。
- 支持 Command 多选、分割、普通删除、波纹删除和 Undo/Redo。
- 视频片段显示音频波形；无视频区间在合成输出中保持静音。
- FIT 中的暂停会保留在运动时间轴中，暂停期间数据保持在暂停边缘值。

### 2.3 数据浮层

当前可用组件包括：

- 基础运动：速度、配速、心率、步频、热量、累计爬升、步幅、功率。
- 跑姿数据：垂直振幅、触地时间、触地时间占比、触地平衡、垂直比、呼吸频率。
- 扩展指标：步速损失、形态功率、空气功率、腿部弹簧刚度。
- 可视化：GPS 路线、距离数值、距离进度、时间与日期、天气。

具体能否显示取决于运动文件是否包含对应字段。GPX 通常只有时间、位置、距离和速度；完整 FIT 往往包含更多指标。

### 2.4 预览与画布

- 视频、黑色空白区和数据浮层使用同一条时间线预览。
- 没有视频但有运动数据时，预览为黑色画布上的数据层。
- 没有视频也没有数据时，预览为黑色画布。
- 可直接拖动组件，调整大小、颜色、透明度、字体和层级。
- 支持网格和拖动吸附。
- 每个运动片段可以使用工程默认布局，也可以保存自己的布局和距离单位。

### 2.5 输出

支持两类输出：

- **透明浮层**：始终保持透明背景，编码可选 HEVC Alpha 或 ProRes 4444。
- **合成视频**：视频存在时显示视频；无视频但有数据时显示黑底数据层；无视频无数据时显示纯黑。编码可选 HEVC 或 H.264。

还可以选择：

- 把整个 in/out 范围输出成一个文件。
- 按范围内的视频片段或运动片段分别输出多个文件。
- 使用源视频规格、常用横竖屏预设或自定义分辨率与帧率。

## 3. 使用前准备

### 3.1 系统要求

- Apple Silicon Mac。
- macOS 13 Ventura 或更新版本。
- App Store 版本需要有效购买记录；购买状态异常时可尝试恢复购买。

### 3.2 素材建议

视频方面：

- 尽量保留原始文件和原始创建时间。
- 横屏、竖屏、不同分辨率和不同帧率可以放在同一工程。
- 如果多个片段来自同一次运动，按拍摄顺序命名会更容易整理。
- 不要在 Finder 中移动或删除工程正在引用的文件；必须移动时，之后使用“重新链接”。

运动数据方面：

- 优先使用设备导出的原始 FIT。
- GPX 可用于路线、距离、速度和配速，但通常缺少心率、功率及跑姿字段。
- 运动文件和视频应来自同一次活动。
- 如果运动中使用了暂停，时间线上会保留暂停占用的现实时间，不会把暂停区间压缩掉。

### 3.3 先理解两个时间

每个片段都有两套时间：

- **时间线时间**：片段放在整个工程的什么位置。
- **素材时间**：片段当前从源文件的第几秒开始读取。

右侧片段检查器会显示：

- **时间线开始**：可编辑，用来精确移动整个片段。
- **素材入点**：只读，由左侧裁剪手柄决定。
- **时长**：只读，由片段两端裁剪决定。

普通对齐只需要移动片段，不需要修改素材本身。

## 4. 界面结构

主窗口可以分为五个区域：

1. **左侧素材与画布栏**：导入素材、查看使用/离线状态、设置网格、管理布局预设。
2. **中央预览画布**：查看当前时间的最终画面，选择和拖动数据组件。
3. **预览控制条**：播放、暂停、逐帧、时间滑块、预览缩放和全屏。
4. **底部时间线**：排列视频与运动片段、管理轨道、裁剪、分割和设置导出范围。
5. **右侧检查器**：选中数据组件时编辑样式；选中时间线片段时编辑片段时间与布局。

右上角“输出”按钮会打开输出面板。底部不再有独立的“同步”或“裁剪”页面：时间对齐、片段裁剪和导出范围都直接在时间线上完成。

## 5. 第一次完成一个工程

### 第 1 步：导入素材

在左侧“素材”区域：

1. 点击“视频”或“导入视频…”，选择一个或多个视频。
2. 点击“运动文件”或“导入运动文件…”，选择 FIT/GPX。
3. 等待素材行显示时长；视频还会显示分辨率。
4. 确认时间线上出现对应片段。

快捷键：

- 打开视频：`⌘O`
- 打开运动文件：`⌘F`

多选导入的所有内容会自动加入时间线。若只想把素材放进媒体池而暂时不使用，可以在导入后从时间线删除片段；媒体池中的素材仍会保留。

### 第 2 步：整理时间线

新素材默认向后追加，不会为了每个素材自动新建轨道。你可以：

- 左右拖动片段改变时间线位置。
- 上下拖到同类轨道完成换轨。
- 从媒体池把素材直接拖到目标轨道和目标时间。
- 点击素材行右侧“加入时间线”，从工程末尾追加一个新实例。

如果需要更多轨道，点击时间线右上角“新增轨道”，选择：

- 新增视频轨道。
- 新增运动数据轨道。

### 第 3 步：对齐视频与运动数据

时间对齐的本质是让同一事件在两种素材中落到同一个时间线位置。

最常见的方法：

1. 在视频中找到清晰事件，例如起跑、经过路牌、补给点或转弯。
2. 确认该事件在视频素材中发生的时间。
3. 确认同一事件在运动文件中发生的运动时间。
4. 拖动视频或运动片段，使两个事件位于同一条红色播放头下。
5. 播放事件前后几秒，检查距离、路线和配速变化。

需要精确输入时：

1. 点击时间线片段。
2. 在右侧“时间线片段”检查器找到“时间线开始”。
3. 输入小时、分钟、秒和毫秒。

未裁剪片段的快速计算公式是：

```text
运动片段时间线开始
= 视频片段时间线开始 + 视频中的匹配时间 - 运动中的匹配时间
```

如果计算结果为负数，不要把片段放到负时间。把另一类片段整体向后移动，给时间线开头留出空白即可。

已经裁剪过片段时，用检查器显示的“素材入点”修正：

```text
运动片段开始
= 视频片段开始
 +（视频匹配时间 - 视频素材入点）
 -（运动匹配时间 - 运动素材入点）
```

### 第 4 步：裁剪和分割

裁剪片段：

- 拖动片段左手柄：改变素材入点和片段开始位置。
- 拖动片段右手柄：改变片段结束位置。
- 手柄靠近红色播放头、其他片段边缘或时间线起点时会吸附，并显示黄色参考线。

分割片段：

1. 把红色播放头移到切割位置。
2. 如果选中了一个或多个片段，`⌘B` 只分割播放头下的选中片段。
3. 如果没有选中任何片段，`⌘B` 会分割播放头下所有可编辑轨道的片段。

这与 DaVinci Resolve 的常用操作逻辑一致。

### 第 5 步：排布数据组件

1. 把播放头移到有运动数据的位置。
2. 在预览画布上点击某个数据组件。
3. 直接拖动组件到目标位置。
4. 在右侧检查器调整布局、内容、外观、字体和数据设置。
5. 使用“添加”菜单加入更多组件。

建议第一次只保留路线、距离、配速和心率。先保证信息清楚，再增加跑姿或天气数据。

### 第 6 步：设置导出范围

时间线轨道区上方有一对蓝色 in/out 手柄：

- 左侧手柄决定导出开始。
- 右侧手柄决定导出结束。
- 范围外区域会变暗。

拖动手柄，把范围限制到真正需要输出的部分。导出范围和片段裁剪不同：导出范围不会改变片段内容，只决定最终写出哪一段时间线。

### 第 7 步：导出

1. 点击右上角“输出”。
2. 选择分辨率、帧率、渲染方式、编码、码率和距离单位。
3. 选择保存位置。
4. 点击“导出浮层”或“导出视频”。
5. 等待完成通知，再在访达中查看结果。

## 6. 时间线详细操作

### 6.1 选择和多选

- 单击片段：只选中该片段，并在右侧显示片段检查器。
- Command 单击：把片段加入选择或从选择中移除。
- 点击空白时间线：清空片段选择。

多选后可一次分割、删除或波纹删除多个片段。

### 6.2 移动和换轨

- 横向拖动改变片段时间线开始位置。
- 纵向拖到同类轨道，可在一次操作中完成移动和换轨。
- 视频只能进入视频轨，运动片段只能进入运动数据轨。
- 锁定轨道不能接收片段。
- 目标轨已有片段时，软件会寻找离落点最近的可容纳空隙，不会覆盖或推开原片段。

### 6.3 吸附

片段移动和裁剪会吸附到：

- 时间线开始。
- 红色播放头。
- 其他片段的头部或尾部。

命中时会出现黄色竖线和来源提示。想精确对齐某一时刻时，先把播放头放在那里，再拖动片段边缘吸附红线。

### 6.4 删除与波纹删除

- `⌫`：删除选中片段，保留原来的时间空隙。
- `⇧⌫`：波纹删除选中片段，并向前收拢后续内容。
- `⌘Z`：撤销。
- `⇧⌘Z`：重做。

普通剪辑操作不弹确认框；删除正在被时间线使用的媒体池素材、替换整条自定义时间线等破坏性操作会要求确认。

### 6.5 多视频轨覆盖

同一时刻多条视频轨都有片段时：

- 上层已启用的视频轨覆盖下层轨。
- 覆盖结束后，下层视频会从其连续素材时间继续显示。
- 导出音频也跟随当前可见视频片段切换。

当前是全画面覆盖，不是画中画或透明视频混合。

### 6.6 多运动数据轨

- 每条已启用的运动数据轨都会参与合成。
- 不同轨道可使用不同运动文件、布局和距离单位。
- 上层运动轨最后绘制，适合把需要强调的组件放在更上层。
- 同一轨道应尽量避免重叠片段；发生重叠时，以轨道中最后命中的片段为准。

### 6.7 轨道管理

轨道头支持：

- 重命名。
- 启用或禁用。
- 锁定或解锁。
- 删除空白轨道。

禁用轨道不会进入预览和导出。锁定轨道后，片段不能移动、裁剪、分割、删除或接收拖放。轨道过多时，轨道区可以纵向滚动。

### 6.8 缩放和导航

- 使用时间线右上角缩放按钮或滑杆横向缩放。
- 也可以在触控板上捏合。
- 缩放焦点以当前红色播放头为中心。
- `↑` 跳到上一个剪辑点。
- `↓` 跳到下一个剪辑点。
- 跳转后时间线会自动把播放头带回视口。

### 6.9 空白区的画面规则

| 时间线状态 | 预览 / 合成视频 | 透明浮层 |
| --- | --- | --- |
| 有视频、有数据 | 视频上叠加数据 | 只有透明数据层 |
| 有视频、无数据 | 原视频 | 全透明 |
| 无视频、有数据 | 黑色画布上叠加数据 | 透明背景上的数据层 |
| 无视频、无数据 | 纯黑画布 | 全透明 |

因此，运动数据片段完全可以比视频片段更长；这也是记录整次运动、只在中间插入若干拍摄片段时的推荐组织方式。

## 7. 数据组件与布局

### 7.1 添加和选择组件

在右侧检查器顶部使用“添加”菜单。缺少源数据的组件会不可用。例如：

- 没有 GPS，路线不可用。
- 没有心率字段，心率不可用。
- 没有功率或跑姿字段，对应组件不可用。

### 7.2 常用编辑项

选中组件后，可根据组件类型调整：

- 位置、大小和长度。
- 标签、单位、图标及自定义文字。
- 面板、边框、透明度和线宽。
- 字体、字号和颜色。
- 小数位、仪表范围、刻度和天气图标。

顶部操作还包括：显示/隐藏、复制、上移一层、下移一层和删除。

### 7.3 网格与吸附

左侧“画布”区域可设置：

- 显示网格。
- 拖动时吸附。
- 网格列数和行数。

排版时开启网格，完成后关闭网格检查真实效果。

### 7.4 每片段布局

选中运动时间线片段后，右侧可以：

- 设置该片段的米/公里单位。
- “使用当前布局”：把当前画布布局保存到该运动片段。
- “使用默认布局”：让该片段继承工程默认布局。

输出面板中的距离单位与当前选中运动片段的设置同步。

### 7.5 布局预设

左侧可保存、应用、设置默认、导入和导出布局预设。适合：

- 多次比赛使用同一套视觉风格。
- 横屏和竖屏分别保存一套模板。
- 在另一台 Mac 上迁移布局。

应用预设会替换当前画布布局，操作前确认当前修改是否需要保存。

## 8. 天气组件

天气组件需要：

- 运动文件含时间与 GPS。
- 有效的 OpenWeather API key。
- 网络可用，以便第一次获取天气。

天气数据成功获取后会在本机缓存。已经载入完成的天气不会因为渲染中途断网而丢失。

如果工程包含天气组件，但天气尚未载入成功或仍在加载，开始导出时会出现确认提示。建议：

1. 等待天气显示正常。
2. 再开始导出。
3. 只有确定不需要天气时才选择继续。

如果导出结果显示 `--`，先回到预览确认当前运动片段使用的布局、天气缓存和导出范围内的运动素材都正确。

## 9. 输出设置详解

### 9.1 透明浮层与合成视频

选择透明浮层，如果：

- 后续还要调色、加字幕、转场或变速。
- 希望在剪辑软件中随时隐藏或替换数据层。
- 需要把同一数据层叠到不同版本的视频上。

选择合成视频，如果：

- 时间线已经完成，不想进入其他剪辑软件。
- 需要快速输出可直接分享的文件。
- 希望原视频声音一起保留。

### 9.2 渲染范围

- **单个片段**：名称沿用当前界面，实际含义是把整个 in/out 范围输出成一个连续文件。
- **多个单独片段**：合成视频按范围内的视频片段分别输出；透明浮层按范围内的运动片段分别输出。选择此项时需要选择一个输出文件夹。

### 9.3 编码建议

透明浮层：

- HEVC/H.265 Alpha：文件较小，适合常规后期。
- ProRes 4444：文件更大，适合高质量中间文件和更广泛的专业流程。

合成视频：

- HEVC/H.265：压缩效率高，推荐默认使用。
- H.264：兼容性更广，适合对播放设备兼容性要求较高的场景。

### 9.4 分辨率和帧率

常用预设包括：

- 3840×2160、2560×1440、1920×1080、1280×720。
- 2160×3840、1080×1920、720×1280。
- 23.976、24、25、29.97、30、50、59.94、60 fps。

有视频时通常优先使用源视频分辨率和源视频帧率。混合横竖屏片段时，每个片段会按自身方向等比缩放并居中，空余区域使用黑边。

### 9.5 码率

默认值为 12000 kbps。可参考：

- 1080p：8000–16000 kbps。
- 4K：30000–80000 kbps。
- ProRes 4444 不以普通分发视频的码率思路衡量，文件体积会明显更大。

### 9.6 导出前预检

软件会在导出前检查：

- 导出范围内是否有可用视频或运动片段。
- 素材是否离线。
- 片段素材范围是否越界。
- 编码是否与透明/合成模式匹配。
- 天气组件是否准备完成。
- 输出路径是否有写入权限。

按钮不可用时，查看输出按钮下方的原因提示，不要只反复点击。

## 10. 工程保存、打开与素材恢复

### 10.1 保存工程

- 保存：`⌘S`
- 打开时间线工程：`⇧⌘O`

工程 JSON 会保存：

- 媒体池和素材引用。
- 轨道名称、启用和锁定状态。
- 片段位置、素材入点、时长、布局和距离单位。
- 输出分辨率、帧率、编码、码率、in/out 和渲染方式。

输出目标文件路径不会写入工程。

### 10.2 移动工程

如果工程 JSON 与素材位于同一文件夹或其子目录，软件会记录相对路径作为恢复手段。跨机器移动时，推荐把工程和素材一起放进一个总文件夹再整体复制。

### 10.3 重新链接离线素材

素材文件被移动、重命名或权限失效时：

1. 媒体池会显示“离线”和具体原因。
2. 点击链条按钮或“重新链接…”。
3. 选择正确的替代文件。
4. 软件会先验证视频元数据或解析运动文件。
5. 成功后原片段位置、裁剪和布局保持不变。

重新链接支持 Undo/Redo。错误文件不会静默替换原素材。

## 11. 实战案例

### 案例一：相机先拍，49 秒后才开始运动记录

场景：视频从准备阶段开始，手表在视频第 `00:49.000` 才开始记录。

目标：前 49 秒保留视频，但不显示运动数据；49 秒后浮层开始变化。

操作：

1. 把视频片段放在时间线 `00:00.000`。
2. 把完整运动片段放在 `00:49.000`。
3. 把播放头放在 49 秒，拖动运动片段头部吸附红线；也可以在右侧输入 `00:00:49.000`。
4. 从 45 秒开始播放，确认数据在正确时刻出现。
5. 导出合成视频时，前 49 秒是原视频；透明浮层的前 49 秒完全透明。

经验：不要为了“对齐”裁掉运动文件开头。这里最自然的剪辑表达就是让运动片段晚 49 秒开始。

### 案例二：运动开始 5 分 30 秒后才开始录像

场景：手表先开始，视频 `00:00` 对应运动 `05:30`。

推荐组织：

1. 把完整运动片段放在时间线 `00:00`。
2. 把视频片段放在时间线 `05:30`。
3. 如果不想输出前面的黑底数据，把 in 点拖到 `05:30`。
4. 如果想先展示 5 分 30 秒的路线/数据动画，再切入实拍，就保留前段范围。

效果：

- 合成视频在 0–5:30 为黑底数据层，5:30 后出现视频。
- 透明浮层始终透明，仅绘制数据。

经验：允许时间线从空白开始后，不再需要负偏移。把较晚出现的素材放到它真实出现的相对时间即可。

### 案例三：一次长距离活动，只有中间分散拍了三段视频

场景：一份约 110 分钟的 FIT 对应三个按名称排序的视频。三段视频之间存在较大空隙，FIT 中还有两段暂停。

推荐操作：

1. 多选导入三个视频，再导入 FIT。
2. 保持运动片段覆盖完整活动墙钟时间。
3. 根据拍摄创建时间或现场记录，把三个视频移动到各自的相对时间。
4. 视频放在 V1 即可；需要比较或临时覆盖时，把候选片段放到 V2。
5. 播放每个视频片段的开头，用路口、地标或手表读数复核对齐。
6. FIT 暂停区不用手工切开；暂停期间距离和速度会保持，恢复后继续推进。
7. 输出完整合成视频时，无视频区间显示黑底数据层；只导出浮层时，无数据区间保持透明。

经验：运动片段往往是时间线上最长的片段，而视频只是分散在其中的画面证据。这比强行把三个视频首尾拼成一条“伪连续录像”更符合真实运动时间。

### 案例四：给 DaVinci Resolve 制作透明数据层

目标：视频剪辑、调色和声音都留在 DaVinci，只让 DataLayer Studio 生成数据层。

操作：

1. 在 DataLayer Studio 中按 DaVinci 时间线的相对位置排列视频与运动片段。
2. 设置与 DaVinci 工程一致的分辨率和帧率。
3. 选择“透明浮层”。
4. 常规使用选 HEVC Alpha；需要高质量中间文件时选 ProRes 4444。
5. 导出完整 in/out 范围。
6. 在 DaVinci 中把浮层文件放在原视频上方轨道，并保持起点一致。

检查方法：

- 普通播放器显示黑底不代表 Alpha 失败。
- 在 DaVinci 的上层轨道查看透明效果。
- 不要再次给浮层文件做时间拉伸，否则数据会失去同步。

### 案例五：从长时间线批量输出多个社交片段

目标：同一场活动中做多个独立短视频。

操作：

1. 用分割和裁剪整理好多个视频片段。
2. 确保每个短片段对应的数据轨覆盖正确。
3. 在输出面板选择“多个单独片段”。
4. 选择输出文件夹。
5. 导出合成视频时，软件按视频片段分别写出；导出浮层时按运动片段分别写出。

经验：如果各短片需要不同的数据排版，为每个运动片段使用“当前布局”；如果样式统一，就让它们继承默认布局。

### 案例六：工程拷到另一台 Mac 后素材离线

操作：

1. 打开工程 JSON。
2. 对每个标为离线的素材点击“重新链接”。
3. 选择新机器上的对应视频或 FIT。
4. 检查片段位置、素材入点和布局是否保持。
5. 保存一次工程，更新新机器上的访问权限。

经验：先把工程 JSON 和所有素材放在同一个总目录中再复制，恢复最省事。

## 13. 常见问题

### 13.1 数据和视频对不上

排查顺序：

1. 找一个明确匹配事件，不要只凭“看起来差不多”。
2. 检查运动片段和视频片段的时间线开始。
3. 检查片段是否裁剪过；裁剪后要考虑“素材入点”。
4. 检查 FIT 是否包含暂停，运动时间和现实墙钟时间可能不同。
5. 在匹配点前后各播放 5–10 秒复核。

### 13.2 红色播放头不在点击位置

时间线点击、缩放和滚动都使用时间线内容坐标。若发现异常，先确认没有点击左侧轨道头，并尝试把时间线缩放恢复到 1× 后复现。

### 13.3 组件显示 `--`

可能原因：

- 运动文件没有对应字段。
- 当前时间不在运动片段内。
- 该运动片段使用了另一套布局。
- 天气尚未加载或缓存不可用。

### 13.4 导出的透明浮层看起来是黑底

很多播放器不会正确显示 Alpha。请在 DaVinci Resolve、Final Cut Pro 或 Premiere 的上层轨道检查。也可改用 ProRes 4444 交叉验证。

### 13.5 导出按钮不可用

查看按钮下方提示，常见原因包括：

- in/out 范围内没有对应类型片段。
- 素材离线。
- 片段读取范围超出源素材。
- 透明模式选择了非 Alpha 编码，或合成模式选择了 Alpha 编码。
- 尚未选择输出位置。

### 13.6 合成视频中的空白为什么是黑色

这是设计行为：普通视频没有 Alpha 通道。无视频区间使用黑色画布；如果该区间有运动数据，数据会叠在黑色画布上。需要透明背景时请选择“透明浮层”。

### 13.7 天气会不会在渲染中途因断网丢失

不会。天气成功取得后使用本地缓存参与渲染。风险只发生在开始导出前尚未成功载入天气时，此时软件会询问是否继续。

### 13.8 长视频导出失败

检查：

- 目标磁盘剩余空间。
- 输出目录写入权限。
- 分辨率、帧率和码率是否过高。
- 源视频能否被系统正常解码。
- 调试控制台中的“导出”日志。

DataLayer Studio 按帧流式处理，不会把整段视频缓存到内存，但 4K、长时长和 ProRes 4444 仍需要足够磁盘空间。

## 14. 命令行使用

图形界面适合多轨编辑；命令行适合自动化和复用既有工程。

### 14.1 单视频与单运动文件

```bash
swift run overlay \
  --video /path/to/run.mov \
  --fit /path/to/activity.fit \
  --output /path/to/overlay.mov
```

常用参数：

```text
--export-mode overlay|video
--width 1920 --height 1080
--fps 30
--codec hevc-alpha|prores-4444|hevc|h264
--bitrate 12000
--distance-unit km|m
--layout-preset "Race Layout"
--skip-fit-crc
--inspect
```

单源 CLI 仍支持 `--fit-start`、`--sync-video` / `--sync-fit` 和旧版 `--offset`；这些是命令行兼容能力，不代表 App 仍有独立同步面板。

### 14.2 按时间线工程导出

```bash
swift run overlay \
  --timeline-project /path/to/project.dlsproj \
  --output /path/to/output.mov \
  --export-mode video
```

使用 `--timeline-project` 时，不要再混用 `--fit`、`--video`、同步参数或布局预设。工程中的多轨结构由同一套核心渲染逻辑读取。

## 15. 导出前最终检查清单

- [ ] 所有使用中的视频和运动文件都在线。
- [ ] 视频与运动数据在至少一个明确事件上对齐。
- [ ] FIT 暂停区间的表现符合预期。
- [ ] 上层视频轨覆盖关系正确。
- [ ] 运动片段使用了正确布局和距离单位。
- [ ] 天气组件已加载完成，或确定不需要天气。
- [ ] 数据组件没有遮住主体、字幕和安全区域。
- [ ] in/out 范围正确。
- [ ] 分辨率、帧率、编码和码率适合目标平台。
- [ ] 透明浮层与剪辑软件时间线从同一时刻开始。
- [ ] 目标磁盘空间和写入权限充足。
- [ ] 重要工程已经 `⌘S` 保存。

完成这些检查后再开始长时间或 4K 输出，可以避免大多数返工。
