# DataLayer Studio 快速上手：导出第一条数据浮层

最后更新：2026-07-11

这份短指南演示从导入素材到导出透明浮层的最短流程。完整的多轨操作、功能说明与实战案例见 [DataLayer Studio 功能说明与使用手册](user-guide/zh-Hans.md)。

示例文件：

- 视频：`run-original.mov`
- 运动数据：`run.fit` 或 `run.gpx`
- 输出：`run-overlay.mov`

## 1. 导入视频和运动数据

1. 打开 DataLayer Studio。
2. 在左侧“素材”区域点击“视频”，选择 `run-original.mov`。
3. 点击“运动文件”，选择 `run.fit` 或 `run.gpx`。
4. 确认两个素材都出现在媒体池和底部时间线。

快捷键：视频 `⌘O`，运动文件 `⌘F`。

如果一次多选多个文件，所选素材会全部加入时间线；已有内容时会从工程末尾继续追加。

## 2. 在时间线上对齐

App 不再使用独立“同步”面板。视频和运动数据的对齐直接通过片段相对位置完成。

### 相机先拍，之后才开始运动记录

例如运动在视频第 `00:49` 开始：

1. 视频片段保持从时间线 `00:00` 开始。
2. 把运动片段拖到 `00:49`。
3. 可先把红色播放头放在 49 秒，再让运动片段头部吸附红线。
4. 也可以选中运动片段，在右侧“时间线开始”输入 `00:00:49.000`。

### 运动先开始，之后才开始录像

例如视频开头对应运动第 `05:30`：

1. 运动片段保持从时间线 `00:00` 开始。
2. 把视频片段放到时间线 `05:30`。
3. 如果不需要前 5 分 30 秒，把时间线 in 点拖到 `05:30`。

播放匹配点前后几秒，检查距离、路线和配速变化是否合理。

## 3. 简单调整数据组件

1. 把播放头移到运动片段范围内。
2. 在预览画布上点击一个数据组件。
3. 直接拖动组件到合适位置。
4. 在右侧检查器调整大小、颜色、字体或标签。
5. 第一次建议只保留路线、距离、配速和心率。

## 4. 设置导出范围

在时间线中拖动蓝色 in/out 手柄：

- 左侧手柄是导出开始。
- 右侧手柄是导出结束。
- 范围外区域会变暗。

它们只决定输出范围，不会裁坏片段或源文件。

## 5. 导出透明浮层

1. 点击右上角“输出”。
2. 分辨率和帧率通常选择源视频规格。
3. 渲染选择“单个片段”，输出整个 in/out 范围。
4. 编码选择 HEVC/H.265 Alpha；需要高质量中间文件时选 ProRes 4444。
5. 选择目标 `run-overlay.mov`。
6. 点击“导出浮层”。

导出后，在 DaVinci Resolve、Final Cut Pro 或 Premiere 中：

1. 把原视频放在下方轨道。
2. 把 `run-overlay.mov` 放在上方轨道。
3. 让两个文件使用同一个时间线起点。

普通播放器显示黑底不一定是失败；很多播放器不会正确显示 Alpha，请在剪辑软件的上层轨道检查。

## 6. 如果想直接得到成片

在输出面板点击“导出视频”，编码选择 HEVC 或 H.264。

合成视频的空白规则：

- 无视频、有数据：黑色画布上显示数据。
- 无视频、无数据：纯黑画布。
- 有视频、无数据：只显示原视频。

## 7. 导出前快速检查

- 视频和运动文件都在线。
- 至少用一个明确事件验证过对齐。
- 数据组件没有遮住主体。
- 天气组件已加载完成，或确定不需要天气。
- in/out 范围、分辨率、帧率和编码正确。
- 目标磁盘有足够空间和写入权限。
