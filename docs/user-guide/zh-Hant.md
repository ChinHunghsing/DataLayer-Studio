# DataLayer Studio 功能說明與使用手冊

最後更新：2026-07-16

適用版本：macOS 0.3.3

DataLayer Studio 是一款面向跑步、騎行和戶外運動影片的資料浮層製作工具。它把影片素材與 `.fit` / `.gpx` 運動記錄放進同一條多軌時間線，在即時預覽中排布速度、配速、心率、路線、距離、天氣等元件，最後輸出透明浮層或已經合成好的影片。

這份文件分為三部分：

1. 功能說明：先了解軟體能做什麼、不能做什麼。
2. 使用手冊：從新增工程到匯出的完整操作流程。
3. 實戰案例：用常見拍攝場景說明怎樣組織和對齊複雜時間線。

## 1. 軟體適合做什麼

典型用途包括：

- 為比賽回顧影片疊加路線、距離、配速和心率。
- 為訓練復盤影片展示步頻、功率、跑姿和海拔資料。
- 把一整次運動中分散拍攝的多個影片片段放回正確的運動時間。
- 輸出透明 Alpha 浮層，交給 DaVinci Resolve、Final Cut Pro 或 Premiere 繼續剪輯。
- 直接輸出帶原影片、原聲音和資料浮層的成片。
- 儲存工程、版面範本和匯出預設，在下一條影片中繼續使用。

DataLayer Studio 遵循「剪輯邏輯標準、互動保持輕量」的原則。時間線支援多影片軌、多運動資料軌、片段移動、裁切、分割、複製貼上、多選、吸附、鎖軌和復原，但目前不是完整的非線性剪輯軟體：

- 暫不包含轉場、變速、畫中畫、關鍵影格和多機位切換工具。
- 影片軌重疊時，上層影片整個畫面覆蓋下層影片。
- 運動資料軌用於疊加資料元件，不用於混合兩個影片畫面。

## 2. 核心功能一覽

### 2.1 素材與工程

- 匯入一個或多個影片檔案，以及一個或多個 `.fit` / `.gpx` 運動檔案。
- Finder 多選匯入時，所選素材會按順序自動加入時間線；時間線已有內容時從工程末尾繼續追加。
- 檔案可以直接從 Finder 拖進媒體庫或時間線軌道：拖到媒體庫只入庫，拖到時間線會同時入庫並放到落點位置。
- 影片和運動檔案都帶可靠拍攝時間時，會按絕對時間自動對齊；匯入先後順序不影響結果。
- 媒體庫會標記哪些素材「使用中」，離線素材可重新連結。
- 工程使用專屬 `.dlsproj` 檔案，儲存素材引用、軌道、片段、版面、匯出設定、播放頭位置和已取得的天氣資料，並相容舊版 `.json` 工程。

### 2.2 標準多軌時間線

- 影片軌與運動資料軌都可以有多條；片段可自由移動，時間線開頭、片段之間和結尾都允許留白。
- 片段兩端可裁切；裁切會改變素材入點或出點。
- 片段可複製、剪下、貼上和插入貼上，也可以在空白處按右鍵貼上。
- 片段頭尾可吸附時間線起點、紅色播放頭和其他片段邊緣；吸附可以在時間線工具列一鍵開關。
- 支援 Command 多選、播放頭處分割、普通刪除、波紋刪除和復原/重做。
- `,` / `.` 可把選中片段逐格左右微移；Shift 拖動跨軌時鎖定水平位置。
- 可暫時停用片段而不刪除；停用片段不參與預覽、匯出和剪輯點跳轉。
- 影片片段顯示音訊波形；無影片區間在合成輸出中保持靜音。
- FIT 中的暫停會保留在運動時間軸中，暫停期間資料保持在暫停邊緣值。

### 2.3 資料浮層

目前可用元件包括：

- 基礎運動：速度、配速、心率、步頻、熱量、累計爬升、步幅、功率。
- 跑姿資料：垂直振幅、觸地時間、觸地時間占比、觸地平衡、垂直比、呼吸頻率。
- 擴充指標：步速損失、形態功率、空氣功率、腿部彈簧剛度。
- 視覺化：GPS 路線、距離數值、距離進度、時間與日期、天氣。

具體能否顯示取決於運動檔案是否包含對應欄位。GPX 通常只有時間、位置、距離和速度；完整 FIT 往往包含更多指標。

### 2.4 預覽與畫布

- 影片、黑色空白區和資料浮層使用同一條時間線預覽；沒有影片時預覽為黑色畫布上的資料層。
- 元件可直接拖動，支援多選、部件子選擇和智慧參考線吸附。
- 「排列」選單與右鍵選單提供圖層調整、對齊、分布和複製/貼上樣式。
- 每個運動片段可以使用工程預設版面，也可以儲存自己的版面和距離單位。

### 2.5 匯出

匯出中心（`⌘E`）把預設、設定、進度和結果放在同一個視窗中：

- **透明浮層**：始終保持透明背景，編碼可選 HEVC Alpha 或 ProRes 4444。
- **合成影片**：影片存在時顯示影片；無影片但有資料時顯示黑底資料層；無影片無資料時顯示純黑。編碼可選 HEVC 或 H.264。
- 渲染範圍可選「完整時間線」（輸出一個檔案）或「多個單獨片段」（按片段分別輸出）。
- 內建五個匯出預設，自己的常用設定可儲存為「我的預設」。

## 3. 使用前準備

### 3.1 系統需求

- Apple Silicon Mac。
- macOS 13 Ventura 或更新版本。
- App Store 版本需要有效購買記錄；購買狀態異常時可嘗試恢復購買。

### 3.2 素材建議

影片方面：

- 盡量保留原始檔案和原始建立時間；自動對表依賴拍攝時間中繼資料。
- 橫向、直向、不同解析度和不同影格率可以放在同一工程。
- 不要在 Finder 中移動或刪除工程正在引用的檔案；必須移動時，之後使用「重新連結」。

運動資料方面：

- 優先使用裝置匯出的原始 FIT。
- GPX 可用於路線、距離、速度和配速，但通常缺少心率、功率及跑姿欄位。
- 運動檔案和影片應來自同一次活動。
- 運動中使用了暫停時，時間線上會保留暫停佔用的現實時間，不會把暫停區間壓縮掉。

### 3.3 先理解兩個時間

每個片段都有兩套時間：

- **時間線時間**：片段放在整個工程的什麼位置。
- **素材時間**：片段目前從來源檔案的第幾秒開始讀取。

右側片段檢查器會顯示：

- **時間線開始**：可編輯，用來精確移動整個片段。
- **素材入點**：唯讀，由左側裁切控制點決定。
- **時長**：唯讀，由片段兩端裁切決定。

普通對齊只需要移動片段，不需要修改素材本身。

## 4. 介面結構

主視窗可以分為五個區域：

1. **左側「資料庫」面板**：在「素材 / 元件 / 範本」三頁中匯入素材、瀏覽元件和管理使用者範本。
2. **中央預覽畫布**：查看目前時間的最終畫面，選擇和拖動資料元件。
3. **預覽控制列**：播放、暫停、逐格、時間碼、預覽縮放和全螢幕。
4. **底部時間線**：排列影片與運動片段、管理軌道、裁切、分割和複製貼上。
5. **右側檢查器**：選中資料元件時編輯樣式；選中時間線片段時編輯片段時間與版面。

頂部工具列可顯示或摺疊資料庫、時間線和檢查器（`⌥⌘1` / `⌥⌘2` / `⌥⌘3`），左右面板寬度可以拖動調整；右上角「輸出」按鈕或 `⌘E` 開啟匯出中心。時間對齊、片段裁切和分割都直接在時間線上完成，沒有獨立的「同步」或「裁切」頁面。

瞬時訊息（儲存成功、匯出失敗原因等）以右下角 toast 顯示，最多同時三條、幾秒後自動消失。更完整的執行記錄在「除錯 > 顯示除錯主控台」（`⇧⌘D`）。

啟動時只顯示歡迎視窗：新增工程、開啟現有工程、瀏覽最近工程和「我的範本」，或把工程、影片、FIT、GPX 直接拖進視窗任意位置。載入運動檔案後，視窗標題優先顯示「活動日期 + 運動類型」，例如「2026-07-05 跑步」。

## 5. 第一次完成一個工程

### 第 1 步：匯入素材

在左側「資料庫 > 素材」中：

1. 使用拖放區域或「匯入影片…」「匯入運動檔案…」按鈕選擇素材，也可以直接把檔案從 Finder 拖進媒體庫或時間線。
2. 等待素材列顯示時長；影片還會顯示解析度。
3. 確認時間線上出現對應片段。

如果影片中繼資料與 FIT/GPX 都包含可靠的拍攝時間，軟體會自動按真實時間排列並對齊片段。建議仍在一個明確事件處播放複核；拍攝時間缺失、相差過大或軌道被鎖定時，按後文手動方法調整。

快捷鍵：開啟影片 `⌘O`，開啟運動檔案 `⌘F`。

### 第 2 步：整理時間線

新素材預設向後追加，不會為每個素材自動新增軌道。你可以：

- 左右拖動片段改變時間線位置；上下拖到同類軌道完成換軌（按住 Shift 鎖定水平位置）。
- 從媒體庫把素材直接拖到目標軌道和目標時間。
- 點擊素材列右側「加入時間線」，從工程末尾追加一個新實例。

需要更多軌道時，點擊時間線右上角「新增軌道」，選擇新增影片軌道或運動資料軌道。

### 第 3 步：對齊影片與運動資料

時間對齊的本質是讓同一事件在兩種素材中落到同一個時間線位置。

最常見的方法：

1. 在影片中找到清晰事件，例如起跑、經過路牌、補給點或轉彎。
2. 確認該事件在影片素材中發生的時間。
3. 確認同一事件在運動檔案中發生的運動時間。
4. 拖動影片或運動片段，使兩個事件位於同一條紅色播放頭下。
5. 播放事件前後幾秒，檢查距離、路線和配速變化。

需要精確輸入時：選中片段，在右側「時間線片段」檢查器的「時間線開始」輸入小時、分鐘、秒和毫秒；也可以用 `,` / `.` 逐格微移。

未裁切片段的快速計算公式是：

```text
運動片段時間線開始
= 影片片段時間線開始 + 影片中的匹配時間 - 運動中的匹配時間
```

如果計算結果為負數，不要把片段放到負時間。把另一類片段整體向後移動，給時間線開頭留出空白即可。

已經裁切過片段時，用檢查器顯示的「素材入點」修正：

```text
運動片段開始
= 影片片段開始
 +（影片匹配時間 - 影片素材入點）
 -（運動匹配時間 - 運動素材入點）
```

### 第 4 步：裁切和分割

裁切片段：

- 拖動片段左控制點：改變素材入點和片段開始位置。
- 拖動片段右控制點：改變片段結束位置。
- 控制點靠近紅色播放頭、其他片段邊緣或時間線起點時會吸附並顯示參考線；不需要時可在時間線工具列關閉吸附。

分割片段：

1. 把紅色播放頭移到切割位置。
2. 如果選中了一個或多個片段，`⌘B` 只分割播放頭下的選中片段。
3. 如果沒有選中任何片段，`⌘B` 會分割播放頭下所有可編輯軌道的片段。

這與 DaVinci Resolve 的常用操作邏輯一致。

### 第 5 步：排布資料元件

1. 把播放頭移到有運動資料的位置。
2. 在「資料庫 > 元件」中雙擊元件加入畫布，或直接拖到目標位置。
3. 在畫布上拖動元件；智慧參考線會幫助對齊其他元件、畫布中線和安全框。
4. 在右側檢查器調整版面、樣式和資料設定。

建議第一次只保留路線、距離、配速和心率。先保證資訊清楚，再增加跑姿或天氣資料。

### 第 6 步：匯出

1. 點擊右上角「輸出」或按 `⌘E` 開啟匯出中心。
2. 在左側選擇一個內建預設，或直接調整右側的渲染方式、尺寸、影格率、編碼和位元率。
3. 選擇儲存位置（「多個單獨片段」模式選擇輸出資料夾）。
4. 點擊匯出按鈕，進度就地顯示；完成後可直接在 Finder 中查看結果。

## 6. 時間線詳細操作

### 6.1 選擇和多選

- 單擊片段：只選中該片段，並在右側顯示片段檢查器。
- Command 單擊：把片段加入選擇或從選擇中移除。
- 點擊空白時間線：清空片段選擇。

多選後可一次移動、分割、刪除、波紋刪除或複製多個片段。

### 6.2 移動和換軌

- 橫向拖動改變片段時間線開始位置；按住 Shift 拖動可在換軌時鎖定水平位置。
- 縱向拖到同類軌道，可在一次操作中完成移動和換軌。
- 影片只能進入影片軌，運動片段只能進入運動資料軌；鎖定軌道不能接收片段。
- 目標軌已有片段時，軟體會尋找離落點最近的可容納空隙，不會覆蓋或推開原片段。

### 6.3 複製、剪下與貼上

- `⌘C` 複製、`⌘X` 剪下選中片段。
- `⌘V` 貼上到播放頭位置。
- `⇧⌘V` 插入貼上：貼上的同時把該軌後續片段向後讓位。
- 也可以在時間線空白處按右鍵選擇「貼上」，把片段貼到點擊位置。

### 6.4 吸附

片段移動和裁切會吸附到：時間線開始、紅色播放頭、其他片段的頭部或尾部。命中時會出現參考線和來源提示。想精確對齊某一時刻時，先把播放頭放在那裡，再拖動片段邊緣吸附紅線。時間線工具列的磁鐵開關可暫時關閉吸附。

### 6.5 刪除與波紋刪除

- `⌫`：刪除選中片段，保留原來的時間空隙。
- `⇧⌫`：波紋刪除選中片段，並向前收攏後續內容。
- `⌘Z` 復原，`⇧⌘Z` 重做。

普通剪輯操作不彈確認框；刪除正在被時間線使用的媒體庫素材等破壞性操作會要求確認。

### 6.6 多影片軌覆蓋

同一時刻多條影片軌都有片段時：

- 上層已啟用的影片軌覆蓋下層軌。
- 覆蓋結束後，下層影片會從其連續素材時間繼續顯示。
- 匯出音訊也跟隨目前可見影片片段切換。

目前是全畫面覆蓋，不是畫中畫或透明影片混合。

### 6.7 多運動資料軌

- 每條已啟用的運動資料軌都會參與合成。
- 不同軌道可使用不同運動檔案、版面和距離單位。
- 上層運動軌最後繪製，適合把需要強調的元件放在更上層。
- 同一軌道應盡量避免重疊片段；發生重疊時，以軌道中最後命中的片段為準。

### 6.8 軌道管理

軌道頭支援重新命名、啟用/停用、鎖定/解鎖和刪除空白軌道。停用軌道不會進入預覽和匯出；鎖定軌道後，片段不能移動、裁切、分割、刪除或接收拖放。軌道過多時，軌道區可以縱向捲動。

### 6.9 暫時停用片段

- 選中一個或多個片段後按 `D`，可在啟用與停用之間切換。
- 停用片段會變暗，但仍保留在原軌道和原時間位置，適合暫時比較方案。
- 停用片段不參與預覽、匯出、剪輯點跳轉或輸出預檢。
- 停用片段與停用整條軌道是兩套獨立開關。

### 6.10 縮放和導覽

- 使用時間線右上角縮放控制項橫向縮放，也可以在觸控板上捏合；縮放以目前紅色播放頭為錨點。
- `↑` / `↓` 跳到上一個 / 下一個剪輯點，跳轉後播放頭自動回到視口。
- 播放頭可直接在標尺上點擊或拖動，靠近片段邊緣時會吸附。

### 6.11 空白區的畫面規則

| 時間線狀態 | 預覽 / 合成影片 | 透明浮層 |
| --- | --- | --- |
| 有影片、有資料 | 影片上疊加資料 | 只有透明資料層 |
| 有影片、無資料 | 原影片 | 全透明 |
| 無影片、有資料 | 黑色畫布上疊加資料 | 透明背景上的資料層 |
| 無影片、無資料 | 純黑畫布 | 全透明 |

因此，運動資料片段完全可以比影片片段更長；這也是記錄整次運動、只在中間插入若干拍攝片段時的推薦組織方式。

## 7. 資料元件與畫布

### 7.1 加入和選擇元件

在「資料庫 > 元件」中瀏覽或搜尋全部元件，雙擊加入到預設位置，也可以拖到畫布指定位置。右側檢查器頂部的「加入」選單仍可使用。缺少來源資料的元件會保持可見但不可加入，例如沒有 GPS 時路線不可用、沒有心率欄位時心率不可用。

畫布上支援：

- 單擊選中元件；Command 單擊多選。
- 點擊元件內部的標籤、數值、單位等部件可直接進入部件編輯，檢查器自動切換到對應樣式設定。

### 7.2 檢查器與快速控制項

選中元件後，檢查器分為版面、樣式、資料幾個部分，頂部快速控制區始終顯示 X/Y 位置、縮放、長度（支援的元件）和顯示開關。可調整內容包括：

- 位置、大小和長度。
- 標籤、單位、圖示及自訂文字。
- 面板、邊框、透明度和線寬。
- 字體、字號和顏色（可按部件分別設定）。
- 小數位、儀表範圍、刻度和天氣圖示。

距離類元件（距離數值、距離進度）的公尺/公里單位也在各自檢查器中設定。

### 7.3 排列、對齊與樣式複用

「排列」選單和畫布右鍵選單提供：

- 圖層：移到最前、上移一層、下移一層、移到最後（`⌘⌥↑` / `⌘⌥↓` 對應上移/下移）。
- 對齊：左、水平置中、右、頂、垂直置中、底。
- 分布：水平分布、垂直分布（需選中三個及以上元件）。
- 複製樣式 / 貼上樣式：把一個元件的外觀快速套到其他元件。
- 刪除：作用於整個選擇。

### 7.4 智慧參考線、格線與安全框

- 拖動元件時，智慧參考線自動吸附其他元件的邊緣和中心、畫布中線與三分線，以及安全框。
- 「預覽 > 顯示格線」可開啟純視覺參考格線；格線不再需要配置行列數。
- 安全框內縮比例在「設定」中調整（0–20%，預設 5%），用於確保元件不會貼到畫面邊緣。

### 7.5 每片段版面

選中運動時間線片段後，右側可以：

- 設定該片段的公尺/公里單位。
- 「使用目前版面」：把目前畫布版面儲存到該運動片段。
- 「使用預設版面」：讓該片段繼承工程預設版面。

### 7.6 版面範本

在「資料庫 > 範本」中可儲存、套用、設為預設、匯入和匯出使用者版面範本：

- 匯出檔案使用專屬 `.dlspreset` 副檔名；匯入相容舊版 `.json` 預設檔案。
- 適合多次比賽複用同一套視覺風格、橫直向各存一套範本，或遷移到另一台 Mac。

套用範本會替換目前畫布版面，操作前確認目前修改是否需要儲存。軟體不內建範本；歡迎視窗只顯示使用者自己儲存或匯入的範本。

## 8. 天氣元件

天氣元件需要：

- 運動檔案含時間與 GPS。
- 有效的 OpenWeather API key。
- 網路可用，以便第一次取得天氣。

第一次加入天氣元件但尚未設定 Key 時，軟體會顯示申請引導。點擊「取得 API Key」註冊 OpenWeather 帳號，為 Key 開通 One Call 4.0（含每日免費額度），再把 Key 填入檢查器並重新整理天氣；新 Key 可能需要等待一段時間才生效。Key 只儲存在目前這台 Mac。

天氣資料成功取得後會快取進工程。已經載入完成的天氣不會因為渲染中途斷網而遺失，工程重新開啟時也無需再次連網取得。

如果工程包含天氣元件，但天氣尚未載入成功或仍在載入，開始匯出時會出現確認提示。建議等待天氣顯示正常再匯出；只有確定不需要天氣時才選擇繼續。

## 9. 匯出中心詳解

按 `⌘E` 或點擊右上角「輸出」開啟匯出中心。設定、進度和結果都在這一個視窗內完成。

### 9.1 預設

左側為預設清單：

- **內建預設**：透明浮層 · ProRes 4444、透明浮層 · HEVC、合成影片 · 4K HEVC、合成影片 · 1080p H.264、直向影片 · 4K HEVC。
- **我的預設**：把右側目前設定儲存為命名預設，可重複使用和刪除。使用者預設儲存的是具體解析度/影格率數值。

選擇預設後仍可在右側覆蓋任意選項。

### 9.2 透明浮層與合成影片

選擇透明浮層，如果：

- 後續還要調色、加字幕、轉場或變速。
- 希望在剪輯軟體中隨時隱藏或替換資料層。
- 需要把同一資料層疊到不同版本的影片上。

選擇合成影片，如果：

- 時間線已經完成，不想進入其他剪輯軟體。
- 需要快速輸出可直接分享的檔案，並保留原影片聲音。

### 9.3 渲染範圍

- **完整時間線**：把整條時間線輸出成一個連續檔案。
- **多個單獨片段**：合成影片按影片片段分別輸出；透明浮層按運動片段分別輸出。選擇此項時需要指定一個輸出資料夾，檔案按編號命名。

如果只想輸出時間線的一部分，先用裁切、分割和刪除把時間線整理成需要的內容。

### 9.4 編碼建議

透明浮層：

- HEVC/H.265 Alpha：檔案較小，適合常規後期。
- ProRes 4444：檔案更大，適合高品質中間檔案和更廣泛的專業流程。

合成影片：

- HEVC/H.265：壓縮效率高，推薦預設使用。
- H.264：相容性更廣，適合對播放裝置相容性要求較高的場景。

### 9.5 尺寸和影格率

- 常用預設涵蓋 3840×2160 到 720×1280 的橫直向組合，影格率 23.976–60 fps。
- 自訂尺寸支援「鎖定比例」，改寬自動聯動高。
- 有影片時通常優先使用來源影片解析度和影格率。混合橫直向片段時，每個片段按自身方向等比縮放並置中，空餘區域使用黑邊。

### 9.6 位元率

預設值為 12000 kbps。可參考：

- 1080p：8000–16000 kbps。
- 4K：30000–80000 kbps。
- ProRes 4444 不以普通分發影片的位元率思路衡量，檔案體積會明顯更大。

### 9.7 匯出前預檢

軟體會在匯出前檢查：

- 時間線上是否有可用影片或運動片段。
- 素材是否離線。
- 片段素材範圍是否越界。
- 編碼是否與透明/合成模式匹配。
- 天氣元件是否準備完成。
- 輸出路徑是否有寫入權限。

按鈕不可用時，查看匯出按鈕附近的原因提示，不要只反覆點擊。

### 9.8 免費版匯出限制

- Mac App Store 版是付費完整版，匯出沒有任何限制。
- 免費版（GitHub Release 下載、自行編譯和命令列工具）保留全部編輯與預覽功能，但匯出最高 1080p，且成片右下角帶 "Made with DataLayer Studio" 浮水印。
- 設定更高解析度時，免費版會在匯出時自動等比縮小到 1080p 以內，匯出面板會顯示對應提示。
- 於 [Mac App Store](https://apps.apple.com/cn/app/datalayer-studio/id6782545770) 購買完整版即可解鎖全解析度、無浮水印匯出。

## 10. 工程儲存、開啟與素材恢復

### 10.1 儲存工程

- 儲存：`⌘S`；另存為：`⇧⌘S`；開啟工程：`⇧⌘O`。
- 工程檔案預設使用 `.dlsproj` 副檔名；仍可開啟舊版 `.json` 工程。
- 儲存過的工程會出現在「檔案 > 最近開啟」中；歡迎視窗也可直接開啟或定位最近工程。

工程檔案會儲存：

- 媒體庫和素材引用。
- 軌道名稱、啟用和鎖定狀態。
- 片段位置、素材入點、時長、版面和距離單位。
- 匯出尺寸、影格率、編碼、位元率和渲染方式。
- 播放頭位置和已取得的天氣資料。

輸出目標檔案路徑不會寫入工程。

### 10.2 移動工程

如果工程檔案與素材位於同一資料夾或其子目錄，軟體會記錄相對路徑作為恢復手段。跨機器移動時，推薦把工程和素材一起放進一個總資料夾再整體複製。

### 10.3 重新連結離線素材

素材檔案被移動、重新命名或權限失效時：

1. 媒體庫會顯示「離線」和具體原因。
2. 點擊鏈條按鈕或「重新連結…」。
3. 選擇正確的替代檔案。
4. 軟體會先驗證影片中繼資料或解析運動檔案。
5. 成功後原片段位置、裁切和版面保持不變。

重新連結支援復原/重做。錯誤檔案不會靜默替換原素材。

## 11. 實戰案例

### 案例一：相機先拍，49 秒後才開始運動記錄

場景：影片從準備階段開始，手錶在影片第 `00:49.000` 才開始記錄。

目標：前 49 秒保留影片，但不顯示運動資料；49 秒後浮層開始變化。

操作：

1. 把影片片段放在時間線 `00:00.000`。
2. 把完整運動片段放在 `00:49.000`。
3. 把播放頭放在 49 秒，拖動運動片段頭部吸附紅線；也可以在右側輸入 `00:00:49.000`。
4. 從 45 秒開始播放，確認資料在正確時刻出現。
5. 匯出合成影片時，前 49 秒是原影片；透明浮層的前 49 秒完全透明。

經驗：不要為了「對齊」裁掉運動檔案開頭。這裡最自然的剪輯表達就是讓運動片段晚 49 秒開始。

### 案例二：運動開始 5 分 30 秒後才開始錄影

場景：手錶先開始，影片 `00:00` 對應運動 `05:30`。

推薦組織：

1. 把完整運動片段放在時間線 `00:00`。
2. 把影片片段放在時間線 `05:30`。
3. 如果不想輸出前面的黑底資料段，拖動運動片段左控制點裁掉前 5 分 30 秒，再把兩個片段一起移回時間線開頭。
4. 如果想先展示 5 分 30 秒的路線/資料動畫，再切入實拍，就保留原樣。

效果：

- 合成影片在 0–5:30 為黑底資料層，5:30 後出現影片。
- 透明浮層始終透明，僅繪製資料。

經驗：時間線允許從空白開始，不需要負偏移。把較晚出現的素材放到它真實出現的相對時間即可。

### 案例三：一次長距離活動，只有中間分散拍了三段影片

場景：一份約 110 分鐘的 FIT 對應三個按名稱排序的影片。三段影片之間存在較大空隙，FIT 中還有兩段暫停。

推薦操作：

1. 多選匯入三個影片，再匯入 FIT；拍攝時間可靠時軟體會自動把它們放到正確位置。
2. 保持運動片段涵蓋完整活動牆鐘時間。
3. 播放每個影片片段的開頭，用路口、地標或手錶讀數複核對齊，必要時用 `,` / `.` 逐格微調。
4. 影片放在 V1 即可；需要比較或暫時覆蓋時，把候選片段放到 V2。
5. FIT 暫停區不用手工切開；暫停期間距離和速度會保持，恢復後繼續推進。
6. 輸出完整合成影片時，無影片區間顯示黑底資料層；只匯出浮層時，無資料區間保持透明。

經驗：運動片段往往是時間線上最長的片段，而影片只是分散在其中的畫面證據。這比強行把三個影片首尾拼成一條「偽連續錄影」更符合真實運動時間。

### 案例四：給 DaVinci Resolve 製作透明資料層

目標：影片剪輯、調色和聲音都留在 DaVinci，只讓 DataLayer Studio 產生資料層。

操作：

1. 在 DataLayer Studio 中按 DaVinci 時間線的相對位置排列影片與運動片段。
2. 在匯出中心選擇「透明浮層 · HEVC」預設；需要高品質中間檔案時選「透明浮層 · ProRes 4444」。
3. 把尺寸和影格率設定成與 DaVinci 工程一致。
4. 匯出完整時間線。
5. 在 DaVinci 中把浮層檔案放在原影片上方軌道，並保持起點一致。

檢查方法：

- 普通播放器顯示黑底不代表 Alpha 失敗。
- 在 DaVinci 的上層軌道查看透明效果。
- 不要再次給浮層檔案做時間拉伸，否則資料會失去同步。

### 案例五：從長時間線批次輸出多個社群片段

目標：同一場活動中做多個獨立短影片。

操作：

1. 用分割和裁切整理好多個影片片段。
2. 確保每個短片段對應的資料軌覆蓋正確。
3. 在匯出中心選擇渲染範圍「多個單獨片段」。
4. 選擇輸出資料夾。
5. 匯出合成影片時，軟體按影片片段分別寫出；匯出浮層時按運動片段分別寫出。

經驗：如果各短片需要不同的資料排版，為每個運動片段使用「目前版面」；如果樣式統一，就讓它們繼承預設版面。

### 案例六：工程拷到另一台 Mac 後素材離線

操作：

1. 開啟 `.dlsproj` 工程。
2. 對每個標為離線的素材點擊「重新連結」。
3. 選擇新機器上的對應影片或 FIT。
4. 檢查片段位置、素材入點和版面是否保持。
5. 儲存一次工程，更新新機器上的存取權限。

經驗：先把工程檔案和所有素材放在同一個總目錄中再複製，恢復最省事。

## 13. 常見問題

### 13.1 資料和影片對不上

排查順序：

1. 找一個明確匹配事件，不要只憑「看起來差不多」。
2. 檢查運動片段和影片片段的時間線開始。
3. 檢查片段是否裁切過；裁切後要考慮「素材入點」。
4. 檢查 FIT 是否包含暫停，運動時間和現實牆鐘時間可能不同。
5. 在匹配點前後各播放 5–10 秒複核。

### 13.2 自動對表沒有生效

自動對表依賴影片檔案的拍攝時間中繼資料和運動檔案的開始時間。轉碼、剪輯軟體二次匯出或從聊天工具下載的影片常常遺失原始拍攝時間。此時手動對齊即可；剪輯軟體匯出的影片不會誤觸發自動對表。

### 13.3 元件顯示 `--`

可能原因：

- 運動檔案沒有對應欄位。
- 目前時間不在運動片段內。
- 該運動片段使用了另一套版面。
- 天氣尚未載入或快取不可用。

### 13.4 匯出的透明浮層看起來是黑底

很多播放器不會正確顯示 Alpha。請在 DaVinci Resolve、Final Cut Pro 或 Premiere 的上層軌道檢查。也可改用 ProRes 4444 交叉驗證。

### 13.5 匯出按鈕不可用

查看匯出中心內的提示，常見原因包括：

- 時間線上沒有對應類型的片段。
- 素材離線。
- 片段讀取範圍超出來源素材。
- 透明模式選擇了非 Alpha 編碼，或合成模式選擇了 Alpha 編碼。
- 尚未選擇輸出位置或輸出資料夾。

### 13.6 合成影片中的空白為什麼是黑色

這是設計行為：普通影片沒有 Alpha 通道。無影片區間使用黑色畫布；如果該區間有運動資料，資料會疊在黑色畫布上。需要透明背景時請選擇「透明浮層」。

### 13.7 天氣會不會在渲染中途因斷網遺失

不會。天氣成功取得後隨工程快取參與渲染。風險只發生在開始匯出前尚未成功載入天氣時，此時軟體會詢問是否繼續。

### 13.8 長影片匯出失敗

檢查：

- 目標磁碟剩餘空間。
- 輸出目錄寫入權限。
- 解析度、影格率和位元率是否過高。
- 來源影片能否被系統正常解碼。
- 除錯主控台中的「匯出」記錄。

DataLayer Studio 按影格串流處理，不會把整段影片快取到記憶體，但 4K、長時長和 ProRes 4444 仍需要足夠磁碟空間。

## 14. 命令列使用

圖形介面適合多軌編輯；命令列適合自動化和複用既有工程。

### 14.1 單影片與單運動檔案

```bash
swift run overlay \
  --video /path/to/run.mov \
  --fit /path/to/activity.fit \
  --output /path/to/overlay.mov
```

常用參數：

```text
--export-mode overlay|video
--width 1920 --height 1080
--fps 30
--codec hevc-alpha|prores-4444|hevc|h264
--bitrate 12000
--distance-unit km|m
--layout-preset "Race Layout"
--skip-fit-crc
--inspect
```

單源 CLI 仍支援 `--fit-start`、`--sync-video` / `--sync-fit` 和舊版 `--offset`；這些是命令列相容能力，不代表 App 有獨立同步面板。

### 14.2 按時間線工程匯出

```bash
swift run overlay \
  --timeline-project /path/to/project.dlsproj \
  --output /path/to/output.mov \
  --export-mode video
```

使用 `--timeline-project` 時，不要再混用 `--fit`、`--video`、同步參數或版面預設。工程中的多軌結構由同一套核心渲染邏輯讀取。

## 15. 匯出前最終檢查清單

- [ ] 所有使用中的影片和運動檔案都在線。
- [ ] 影片與運動資料在至少一個明確事件上對齊。
- [ ] FIT 暫停區間的表現符合預期。
- [ ] 上層影片軌覆蓋關係正確。
- [ ] 運動片段使用了正確版面和距離單位。
- [ ] 天氣元件已載入完成，或確定不需要天氣。
- [ ] 資料元件沒有遮住主體、字幕和安全區域。
- [ ] 時間線內容就是要輸出的內容（多餘片段已刪除或停用）。
- [ ] 尺寸、影格率、編碼和位元率適合目標平台。
- [ ] 透明浮層與剪輯軟體時間線從同一時刻開始。
- [ ] 目標磁碟空間和寫入權限充足。
- [ ] 重要工程已經 `⌘S` 儲存。

完成這些檢查後再開始長時間或 4K 輸出，可以避免大多數返工。
