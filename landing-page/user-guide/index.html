DataLayer Studio 功能说明与使用手册

最后更新：2026-07-18

适用版本：macOS 1.0.0

DataLayer Studio 是一款面向跑步、骑行和户外运动视频的数据浮层制作工具。它把视频素材与 .fit / .gpx 运动记录放进同一条多轨时间线，在实时预览中排布速度、配速、心率、路线、距离、天气等组件，最后输出透明浮层或已经合成好的视频。

这份文档分为三部分：

  1. 功能说明：先了解软件能做什么、不能做什么。
  2. 使用手册：从新建工程到导出的完整操作流程。
  3. 实战案例：用常见拍摄场景说明怎样组织和对齐复杂时间线。

1. 软件适合做什么

典型用途包括：

  • 为比赛回顾视频叠加路线、距离、配速和心率。
  • 为训练复盘视频展示步频、功率、跑姿和海拔数据。
  • 把一整次运动中分散拍摄的多个视频片段放回正确的运动时间。
  • 输出透明 Alpha 浮层，交给 DaVinci Resolve、Final Cut Pro 或 Premiere 继续剪辑。
  • 直接输出带原视频、原声音和数据浮层的成片。
  • 保存工程、布局模板和导出预设，在下一条视频中继续使用。

DataLayer Studio 遵循“剪辑逻辑标准、交互保持轻量”的原则。时间线支持多视频轨、多运动数据轨、片段移动、裁剪、分割、复制粘贴、多选、吸附、锁轨和撤销，但当前不是完整的非线性剪辑软件：

  • 暂不包含转场、变速、画中画、关键帧和多机位切换工具。
  • 视频轨重叠时，上层视频整画面覆盖下层视频。
  • 运动数据轨用于叠加数据组件，不用于混合两个视频画面。

2. 核心功能一览

2.1 素材与工程

  • 导入一个或多个视频文件，以及一个或多个 .fit / .gpx 运动文件。
  • Finder 多选导入时，所选素材会按顺序自动加入时间线；时间线已有内容时从工程末尾继续追加。
  • 文件可以直接从 Finder 拖进媒体池或时间线轨道：拖到媒体池只入池，拖到时间线会同时入池并放到落点位置。
  • 视频和运动文件都带可靠拍摄时间时，会按绝对时间自动对齐；导入先后顺序不影响结果。
  • 媒体池会标记哪些素材“使用中”，离线素材可重新链接。
  • 工程使用专属 .dlsproj 文件，保存素材引用、轨道、片段、布局、导出设置、播放头位置和已获取的天气数据，并兼容旧版 .json 工程。

2.2 标准多轨时间线

  • 视频轨与运动数据轨都可以有多条；片段可自由移动，时间线开头、片段之间和结尾都允许留白。
  • 片段两端可裁剪；裁剪会改变素材入点或出点。
  • 片段可复制、剪切、粘贴和插入粘贴，也可以在空白处右键粘贴。
  • 片段头尾可吸附时间线起点、红色播放头和其他片段边缘；吸附可以在时间线工具栏一键开关。
  • 支持 Command 多选、播放头处分割、普通删除、波纹删除和 Undo/Redo。
  • , / . 可把选中片段逐帧左右微移；Shift 拖动跨轨时锁定水平位置。
  • 可临时禁用片段而不删除；禁用片段不参与预览、导出和剪辑点跳转。
  • 视频片段显示音频波形；无视频区间在合成输出中保持静音。
  • FIT 中的暂停会保留在运动时间轴中，暂停期间数据保持在暂停边缘值。

2.3 数据浮层

当前可用组件包括：

  • 基础运动：速度、配速、心率、步频、热量、累计爬升、步幅、功率。
  • 跑姿数据：垂直振幅、触地时间、触地时间占比、触地平衡、垂直比、呼吸频率。
  • 扩展指标：步速损失、形态功率、空气功率、腿部弹簧刚度。
  • 可视化：GPS 路线、距离数值、距离进度、时间与日期、天气。

具体能否显示取决于运动文件是否包含对应字段。GPX 通常只有时间、位置、距离和速度；完整 FIT 往往包含更多指标。

2.4 预览与画布

  • 视频、黑色空白区和数据浮层使用同一条时间线预览；没有视频时预览为黑色画布上的数据层。
  • 组件可直接拖动，支持多选、部件子选择和智能参考线吸附。
  • “排列”菜单与右键菜单提供层级调整、对齐、分布和复制/粘贴样式。
  • 每个运动片段可以使用工程默认布局，也可以保存自己的布局和距离单位。

2.5 导出

导出中心（⌘E）把预设、设置、进度和结果放在同一个窗口中：

  • 透明浮层：始终保持透明背景，编码可选 HEVC Alpha 或 ProRes 4444。
  • 合成视频：视频存在时显示视频；无视频但有数据时显示黑底数据层；无视频无数据时显示纯黑。编码可选 HEVC 或 H.264。
  • 渲染范围可选“完整时间线”（输出一个文件）或“多个单独片段”（按片段分别输出）。
  • 内置五个导出预设，自己的常用设置可保存为“我的预设”。

3. 使用前准备

3.1 系统要求

  • Apple Silicon Mac。
  • macOS 13 Ventura 或更新版本。
  • App Store 版本需要有效购买记录；购买状态异常时可尝试恢复购买。

3.2 素材建议

视频方面：

  • 尽量保留原始文件和原始创建时间；自动对表依赖拍摄时间元数据。
  • 横屏、竖屏、不同分辨率和不同帧率可以放在同一工程。
  • 不要在 Finder 中移动或删除工程正在引用的文件；必须移动时，之后使用“重新链接”。

运动数据方面：

  • 优先使用设备导出的原始 FIT。
  • GPX 可用于路线、距离、速度和配速，但通常缺少心率、功率及跑姿字段。
  • 运动文件和视频应来自同一次活动。
  • 运动中使用了暂停时，时间线上会保留暂停占用的现实时间，不会把暂停区间压缩掉。

3.3 先理解两个时间

每个片段都有两套时间：

  • 时间线时间：片段放在整个工程的什么位置。
  • 素材时间：片段当前从源文件的第几秒开始读取。

右侧片段检查器会显示：

  • 时间线开始：可编辑，用来精确移动整个片段。
  • 素材入点：只读，由左侧裁剪手柄决定。
  • 时长：只读，由片段两端裁剪决定。

普通对齐只需要移动片段，不需要修改素材本身。

4. 界面结构

主窗口可以分为五个区域：

  1. 左侧“库”面板：在“素材 / 组件 / 模板”三页中导入素材、浏览组件和管理用户模板。
  2. 中央预览画布：查看当前时间的最终画面，选择和拖动数据组件。
  3. 预览控制条：播放、暂停、逐帧、时间码、预览缩放和全屏。
  4. 底部时间线：排列视频与运动片段、管理轨道、裁剪、分割和复制粘贴。
  5. 右侧检查器：选中数据组件时编辑样式；选中时间线片段时编辑片段时间与布局。

顶部工具栏可显示或折叠库、时间线和检查器（⌥⌘1 / ⌥⌘2 / ⌥⌘3），左右面板宽度可以拖动调整；右上角“输出”按钮或 ⌘E 打开导出中心。时间对齐、片段裁剪和分割都直接在时间线上完成，没有独立的“同步”或“裁剪”页面。

瞬时消息（保存成功、导出失败原因等）以右下角 toast 显示，最多同时三条、几秒后自动消失。更完整的运行日志在“调试 > 显示调试控制台”（⇧⌘D）。

启动时只显示欢迎窗口：新建工程、打开现有工程、浏览最近工程和“我的模板”，或把工程、视频、FIT、GPX 直接拖进窗口任意位置。载入运动文件后，窗口标题优先显示“活动日期 + 运动类型”，例如“2026-07-05 跑步”。

5. 第一次完成一个工程

第 1 步：导入素材

在左侧“库 > 素材”中：

  1. 使用拖放区域或“导入视频…”“导入运动文件…”按钮选择素材，也可以直接把文件从 Finder 拖进媒体池或时间线。
  2. 等待素材行显示时长；视频还会显示分辨率。
  3. 确认时间线上出现对应片段。

如果视频元数据与 FIT/GPX 都包含可靠的拍摄时间，软件会自动按真实时间排列并对齐片段。建议仍在一个明确事件处播放复核；拍摄时间缺失、相差过大或轨道被锁定时，按后文手动方法调整。

快捷键：打开视频 ⌘O，打开运动文件 ⌘F。

第 2 步：整理时间线

新素材默认向后追加，不会为每个素材自动新建轨道。你可以：

  • 左右拖动片段改变时间线位置；上下拖到同类轨道完成换轨（按住 Shift 锁定水平位置）。
  • 从媒体池把素材直接拖到目标轨道和目标时间。
  • 点击素材行右侧“加入时间线”，从工程末尾追加一个新实例。

需要更多轨道时，点击时间线右上角“新增轨道”，选择新增视频轨道或运动数据轨道。

第 3 步：对齐视频与运动数据

时间对齐的本质是让同一事件在两种素材中落到同一个时间线位置。

最常见的方法：

  1. 在视频中找到清晰事件，例如起跑、经过路牌、补给点或转弯。
  2. 确认该事件在视频素材中发生的时间。
  3. 确认同一事件在运动文件中发生的运动时间。
  4. 拖动视频或运动片段，使两个事件位于同一条红色播放头下。
  5. 播放事件前后几秒，检查距离、路线和配速变化。

需要精确输入时：选中片段，在右侧“时间线片段”检查器的“时间线开始”输入小时、分钟、秒和毫秒；也可以用 , / . 逐帧微移。

未裁剪片段的快速计算公式是：

运动片段时间线开始
= 视频片段时间线开始 + 视频中的匹配时间 - 运动中的匹配时间

如果计算结果为负数，不要把片段放到负时间。把另一类片段整体向后移动，给时间线开头留出空白即可。

已经裁剪过片段时，用检查器显示的“素材入点”修正：

运动片段开始
= 视频片段开始
 +（视频匹配时间 - 视频素材入点）
 -（运动匹配时间 - 运动素材入点）

第 4 步：裁剪和分割

裁剪片段：

  • 拖动片段左手柄：改变素材入点和片段开始位置。
  • 拖动片段右手柄：改变片段结束位置。
  • 手柄靠近红色播放头、其他片段边缘或时间线起点时会吸附并显示参考线；不需要时可在时间线工具栏关闭吸附。

分割片段：

  1. 把红色播放头移到切割位置。
  2. 如果选中了一个或多个片段，⌘B 只分割播放头下的选中片段。
  3. 如果没有选中任何片段，⌘B 会分割播放头下所有可编辑轨道的片段。

这与 DaVinci Resolve 的常用操作逻辑一致。

第 5 步：排布数据组件

  1. 把播放头移到有运动数据的位置。
  2. 在“库 > 组件”中双击组件加入画布，或直接拖到目标位置。
  3. 在画布上拖动组件；智能参考线会帮助对齐其他组件、画布中线和安全框。
  4. 在右侧检查器调整布局、样式和数据设置。

建议第一次只保留路线、距离、配速和心率。先保证信息清楚，再增加跑姿或天气数据。

第 6 步：导出

  1. 点击右上角“输出”或按 ⌘E 打开导出中心。
  2. 在左侧选择一个内置预设，或直接调整右侧的渲染方式、尺寸、帧率、编码和码率。
  3. 选择保存位置（“多个单独片段”模式选择输出文件夹）。
  4. 点击导出按钮，进度就地显示；完成后可直接在访达中查看结果。

6. 时间线详细操作

6.1 选择和多选

  • 单击片段：只选中该片段，并在右侧显示片段检查器。
  • Command 单击：把片段加入选择或从选择中移除。
  • 点击空白时间线：清空片段选择。

多选后可一次移动、分割、删除、波纹删除或复制多个片段。

6.2 移动和换轨

  • 横向拖动改变片段时间线开始位置；按住 Shift 拖动可在换轨时锁定水平位置。
  • 纵向拖到同类轨道，可在一次操作中完成移动和换轨。
  • 视频只能进入视频轨，运动片段只能进入运动数据轨；锁定轨道不能接收片段。
  • 目标轨已有片段时，软件会寻找离落点最近的可容纳空隙，不会覆盖或推开原片段。

6.3 复制、剪切与粘贴

  • ⌘C 复制、⌘X 剪切选中片段。
  • ⌘V 粘贴到播放头位置。
  • ⇧⌘V 插入粘贴：粘贴的同时把该轨后续片段向后让位。
  • 也可以在时间线空白处右键选择“粘贴”，把片段粘贴到点击位置。

6.4 吸附

片段移动和裁剪会吸附到：时间线开始、红色播放头、其他片段的头部或尾部。命中时会出现参考线和来源提示。想精确对齐某一时刻时，先把播放头放在那里，再拖动片段边缘吸附红线。时间线工具栏的磁铁开关可临时关闭吸附。

6.5 删除与波纹删除

  • ⌫：删除选中片段，保留原来的时间空隙。
  • ⇧⌫：波纹删除选中片段，并向前收拢后续内容。
  • ⌘Z 撤销，⇧⌘Z 重做。

普通剪辑操作不弹确认框；删除正在被时间线使用的媒体池素材等破坏性操作会要求确认。

6.6 多视频轨覆盖

同一时刻多条视频轨都有片段时：

  • 上层已启用的视频轨覆盖下层轨。
  • 覆盖结束后，下层视频会从其连续素材时间继续显示。
  • 导出音频也跟随当前可见视频片段切换。

当前是全画面覆盖，不是画中画或透明视频混合。

6.7 多运动数据轨

  • 每条已启用的运动数据轨都会参与合成。
  • 不同轨道可使用不同运动文件、布局和距离单位。
  • 上层运动轨最后绘制，适合把需要强调的组件放在更上层。
  • 同一轨道应尽量避免重叠片段；发生重叠时，以轨道中最后命中的片段为准。

6.8 轨道管理

轨道头支持重命名、启用/禁用、锁定/解锁和删除空白轨道。禁用轨道不会进入预览和导出；锁定轨道后，片段不能移动、裁剪、分割、删除或接收拖放。轨道过多时，轨道区可以纵向滚动。

6.9 临时禁用片段

  • 选中一个或多个片段后按 D，可在启用与禁用之间切换。
  • 禁用片段会变暗，但仍保留在原轨道和原时间位置，适合临时比较方案。
  • 禁用片段不参与预览、导出、剪辑点跳转或输出预检。
  • 禁用片段与禁用整条轨道是两套独立开关。

6.10 缩放和导航

  • 使用时间线右上角缩放控件横向缩放，也可以在触控板上捏合；缩放以当前红色播放头为锚点。
  • ↑ / ↓ 跳到上一个 / 下一个剪辑点，跳转后播放头自动回到视口。
  • 播放头可直接在标尺上点击或拖动，靠近片段边缘时会吸附。

6.11 空白区的画面规则

时间线状态预览 / 合成视频透明浮层
有视频、有数据视频上叠加数据只有透明数据层
有视频、无数据原视频全透明
无视频、有数据黑色画布上叠加数据透明背景上的数据层
无视频、无数据纯黑画布全透明

因此，运动数据片段完全可以比视频片段更长；这也是记录整次运动、只在中间插入若干拍摄片段时的推荐组织方式。

7. 数据组件与画布

7.1 添加和选择组件

在“库 > 组件”中浏览或搜索全部组件，双击添加到默认位置，也可以拖到画布指定位置。右侧检查器顶部的“添加”菜单仍可使用。缺少源数据的组件会保持可见但不可添加，例如没有 GPS 时路线不可用、没有心率字段时心率不可用。

画布上支持：

  • 单击选中组件；Command 单击多选。
  • 点击组件内部的标签、数值、单位等部件可直接进入部件编辑，检查器自动切换到对应样式设置。

7.2 检查器与快速控件

选中组件后，检查器分为布局、样式、数据几个部分，顶部快速控件区始终显示 X/Y 位置、缩放、长度（支持的组件）和显示开关。可调整内容包括：

  • 位置、大小和长度。
  • 标签、单位、图标及自定义文字。
  • 面板、边框、透明度和线宽。
  • 字体、字号和颜色（可按部件分别设置）。
  • 小数位、仪表范围、刻度和天气图标。

距离类组件（距离数值、距离进度）的米/公里单位也在各自检查器中设置。

7.3 排列、对齐与样式复用

“排列”菜单和画布右键菜单提供：

  • 层级：置于顶层、上移一层、下移一层、置于底层（⌘⌥↑ / ⌘⌥↓ 对应上移/下移）。
  • 对齐：左、水平居中、右、顶、垂直居中、底。
  • 分布：水平分布、垂直分布（需选中三个及以上组件）。
  • 复制样式 / 粘贴样式：把一个组件的外观快速套到其他组件。
  • 删除：作用于整个选择。

7.4 智能参考线、网格与安全框

  • 拖动组件时，智能参考线自动吸附其他组件的边缘和中心、画布中线与三分线，以及安全框。
  • “预览 > 显示网格”可打开纯视觉参考网格；网格不再需要配置行列数。
  • 安全框内缩比例在“设置”中调整（0–20%，默认 5%），用于确保组件不会贴到画面边缘。

7.5 每片段布局

选中运动时间线片段后，右侧可以：

  • 设置该片段的米/公里单位。
  • “使用当前布局”：把当前画布布局保存到该运动片段。
  • “使用默认布局”：让该片段继承工程默认布局。

7.6 布局模板

在“库 > 模板”中可保存、应用、设为默认、导入和导出用户布局模板：

  • 导出文件使用专属 .dlspreset 后缀；导入兼容旧版 .json 预设文件。
  • 适合多次比赛复用同一套视觉风格、横竖屏各存一套模板，或迁移到另一台 Mac。

应用模板会替换当前画布布局，操作前确认当前修改是否需要保存。软件不内置模板；欢迎窗口只显示用户自己保存或导入的模板。

8. 天气组件

天气组件需要：

  • 运动文件含时间与 GPS。
  • 有效的 OpenWeather API key。
  • 网络可用，以便第一次获取天气。

第一次添加天气组件但尚未配置 Key 时，软件会显示申请引导。点击“获取 API Key”注册 OpenWeather 账号，为 Key 开通 One Call 4.0（含每日免费额度），再把 Key 填入检查器并刷新天气；新 Key 可能需要等待一段时间才生效。Key 只保存在当前 Mac。

天气数据成功获取后会缓存进工程。已经载入完成的天气不会因为渲染中途断网而丢失，工程重新打开时也无需再次联网获取。

如果工程包含天气组件，但天气尚未载入成功或仍在加载，开始导出时会出现确认提示。建议等待天气显示正常再导出；只有确定不需要天气时才选择继续。

9. 导出中心详解

按 ⌘E 或点击右上角“输出”打开导出中心。设置、进度和结果都在这一个窗口内完成。

9.1 预设

左侧为预设列表：

  • 内置预设：透明浮层 · ProRes 4444、透明浮层 · HEVC、合成视频 · 4K HEVC、合成视频 · 1080p H.264、竖屏视频 · 4K HEVC。
  • 我的预设：把右侧当前设置保存为命名预设，可重复使用和删除。用户预设保存的是具体分辨率/帧率数值。

选择预设后仍可在右侧覆盖任意选项。

9.2 透明浮层与合成视频

选择透明浮层，如果：

  • 后续还要调色、加字幕、转场或变速。
  • 希望在剪辑软件中随时隐藏或替换数据层。
  • 需要把同一数据层叠到不同版本的视频上。

选择合成视频，如果：

  • 时间线已经完成，不想进入其他剪辑软件。
  • 需要快速输出可直接分享的文件，并保留原视频声音。

9.3 渲染范围

  • 完整时间线：把整条时间线输出成一个连续文件。
  • 多个单独片段：合成视频按视频片段分别输出；透明浮层按运动片段分别输出。选择此项时需要指定一个输出文件夹，文件按编号命名。

如果只想输出时间线的一部分，先用裁剪、分割和删除把时间线整理成需要的内容。

9.4 编码建议

透明浮层：

  • HEVC/H.265 Alpha：文件较小，适合常规后期。
  • ProRes 4444：文件更大，适合高质量中间文件和更广泛的专业流程。

合成视频：

  • HEVC/H.265：压缩效率高，推荐默认使用。
  • H.264：兼容性更广，适合对播放设备兼容性要求较高的场景。

9.5 尺寸和帧率

  • 常用预设覆盖 3840×2160 到 720×1280 的横竖屏组合，帧率 23.976–60 fps。
  • 自定义尺寸支持“锁定比例”，改宽自动联动高。
  • 有视频时通常优先使用源视频分辨率和帧率。混合横竖屏片段时，每个片段按自身方向等比缩放并居中，空余区域使用黑边。

9.6 码率

默认值为 12000 kbps。可参考：

  • 1080p：8000–16000 kbps。
  • 4K：30000–80000 kbps。
  • ProRes 4444 不以普通分发视频的码率思路衡量，文件体积会明显更大。

9.7 导出前预检

软件会在导出前检查：

  • 时间线上是否有可用视频或运动片段。
  • 素材是否离线。
  • 片段素材范围是否越界。
  • 编码是否与透明/合成模式匹配。
  • 天气组件是否准备完成。
  • 输出路径是否有写入权限。

按钮不可用时，查看导出按钮附近的原因提示，不要只反复点击。

9.8 免费版导出限制

  • Mac App Store 版是付费完整版，导出没有任何限制。
  • 免费版（GitHub Release 下载、自行编译和命令行工具）保留全部编辑与预览功能，但导出最高 1080p，且成片右下角带 "Made with DataLayer Studio" 水印。
  • 设置更高分辨率时，免费版会在导出时自动等比缩小到 1080p 以内，导出面板会显示对应提示。
  • 在 Mac App Store 购买完整版即可解锁全分辨率、无水印导出。

10. 工程保存、打开与素材恢复

10.1 保存工程

  • 保存：⌘S；另存为：⇧⌘S；打开工程：⇧⌘O。
  • 工程文件默认使用 .dlsproj 后缀；仍可打开旧版 .json 工程。
  • 保存过的工程会出现在“文件 > 最近打开”中；欢迎窗口也可直接打开或定位最近工程。

工程文件会保存：

  • 媒体池和素材引用。
  • 轨道名称、启用和锁定状态。
  • 片段位置、素材入点、时长、布局和距离单位。
  • 导出尺寸、帧率、编码、码率和渲染方式。
  • 播放头位置和已获取的天气数据。

输出目标文件路径不会写入工程。

10.2 移动工程

如果工程文件与素材位于同一文件夹或其子目录，软件会记录相对路径作为恢复手段。跨机器移动时，推荐把工程和素材一起放进一个总文件夹再整体复制。

10.3 重新链接离线素材

素材文件被移动、重命名或权限失效时：

  1. 媒体池会显示“离线”和具体原因。
  2. 点击链条按钮或“重新链接…”。
  3. 选择正确的替代文件。
  4. 软件会先验证视频元数据或解析运动文件。
  5. 成功后原片段位置、裁剪和布局保持不变。

重新链接支持 Undo/Redo。错误文件不会静默替换原素材。

11. 实战案例

案例一：相机先拍，49 秒后才开始运动记录

场景：视频从准备阶段开始，手表在视频第 00:49.000 才开始记录。

目标：前 49 秒保留视频，但不显示运动数据；49 秒后浮层开始变化。

操作：

  1. 把视频片段放在时间线 00:00.000。
  2. 把完整运动片段放在 00:49.000。
  3. 把播放头放在 49 秒，拖动运动片段头部吸附红线；也可以在右侧输入 00:00:49.000。
  4. 从 45 秒开始播放，确认数据在正确时刻出现。
  5. 导出合成视频时，前 49 秒是原视频；透明浮层的前 49 秒完全透明。

经验：不要为了“对齐”裁掉运动文件开头。这里最自然的剪辑表达就是让运动片段晚 49 秒开始。

案例二：运动开始 5 分 30 秒后才开始录像

场景：手表先开始，视频 00:00 对应运动 05:30。

推荐组织：

  1. 把完整运动片段放在时间线 00:00。
  2. 把视频片段放在时间线 05:30。
  3. 如果不想输出前面的黑底数据段，拖动运动片段左手柄裁剪掉前 5 分 30 秒，再把两个片段一起移回时间线开头。
  4. 如果想先展示 5 分 30 秒的路线/数据动画，再切入实拍，就保留原样。

效果：

  • 合成视频在 0–5:30 为黑底数据层，5:30 后出现视频。
  • 透明浮层始终透明，仅绘制数据。

经验：时间线允许从空白开始，不需要负偏移。把较晚出现的素材放到它真实出现的相对时间即可。

案例三：一次长距离活动，只有中间分散拍了三段视频

场景：一份约 110 分钟的 FIT 对应三个按名称排序的视频。三段视频之间存在较大空隙，FIT 中还有两段暂停。

推荐操作：

  1. 多选导入三个视频，再导入 FIT；拍摄时间可靠时软件会自动把它们放到正确位置。
  2. 保持运动片段覆盖完整活动墙钟时间。
  3. 播放每个视频片段的开头，用路口、地标或手表读数复核对齐，必要时用 , / . 逐帧微调。
  4. 视频放在 V1 即可；需要比较或临时覆盖时，把候选片段放到 V2。
  5. FIT 暂停区不用手工切开；暂停期间距离和速度会保持，恢复后继续推进。
  6. 输出完整合成视频时，无视频区间显示黑底数据层；只导出浮层时，无数据区间保持透明。

经验：运动片段往往是时间线上最长的片段，而视频只是分散在其中的画面证据。这比强行把三个视频首尾拼成一条“伪连续录像”更符合真实运动时间。

案例四：给 DaVinci Resolve 制作透明数据层

目标：视频剪辑、调色和声音都留在 DaVinci，只让 DataLayer Studio 生成数据层。

操作：

  1. 在 DataLayer Studio 中按 DaVinci 时间线的相对位置排列视频与运动片段。
  2. 在导出中心选择“透明浮层 · HEVC”预设；需要高质量中间文件时选“透明浮层 · ProRes 4444”。
  3. 把尺寸和帧率设置成与 DaVinci 工程一致。
  4. 导出完整时间线。
  5. 在 DaVinci 中把浮层文件放在原视频上方轨道，并保持起点一致。

检查方法：

  • 普通播放器显示黑底不代表 Alpha 失败。
  • 在 DaVinci 的上层轨道查看透明效果。
  • 不要再次给浮层文件做时间拉伸，否则数据会失去同步。

案例五：从长时间线批量输出多个社交片段

目标：同一场活动中做多个独立短视频。

操作：

  1. 用分割和裁剪整理好多个视频片段。
  2. 确保每个短片段对应的数据轨覆盖正确。
  3. 在导出中心选择渲染范围“多个单独片段”。
  4. 选择输出文件夹。
  5. 导出合成视频时，软件按视频片段分别写出；导出浮层时按运动片段分别写出。

经验：如果各短片需要不同的数据排版，为每个运动片段使用“当前布局”；如果样式统一，就让它们继承默认布局。

案例六：工程拷到另一台 Mac 后素材离线

操作：

  1. 打开 .dlsproj 工程。
  2. 对每个标为离线的素材点击“重新链接”。
  3. 选择新机器上的对应视频或 FIT。
  4. 检查片段位置、素材入点和布局是否保持。
  5. 保存一次工程，更新新机器上的访问权限。

经验：先把工程文件和所有素材放在同一个总目录中再复制，恢复最省事。

13. 常见问题

13.1 数据和视频对不上

排查顺序：

  1. 找一个明确匹配事件，不要只凭“看起来差不多”。
  2. 检查运动片段和视频片段的时间线开始。
  3. 检查片段是否裁剪过；裁剪后要考虑“素材入点”。
  4. 检查 FIT 是否包含暂停，运动时间和现实墙钟时间可能不同。
  5. 在匹配点前后各播放 5–10 秒复核。

13.2 自动对表没有生效

自动对表依赖视频文件的拍摄时间元数据和运动文件的开始时间。转码、剪辑软件二次导出或从聊天工具下载的视频常常丢失原始拍摄时间。此时手动对齐即可；剪辑软件导出的视频不会误触发自动对表。

13.3 组件显示 --

可能原因：

  • 运动文件没有对应字段。
  • 当前时间不在运动片段内。
  • 该运动片段使用了另一套布局。
  • 天气尚未加载或缓存不可用。

13.4 导出的透明浮层看起来是黑底

很多播放器不会正确显示 Alpha。请在 DaVinci Resolve、Final Cut Pro 或 Premiere 的上层轨道检查。也可改用 ProRes 4444 交叉验证。

13.5 导出按钮不可用

查看导出中心内的提示，常见原因包括：

  • 时间线上没有对应类型的片段。
  • 素材离线。
  • 片段读取范围超出源素材。
  • 透明模式选择了非 Alpha 编码，或合成模式选择了 Alpha 编码。
  • 尚未选择输出位置或输出文件夹。

13.6 合成视频中的空白为什么是黑色

这是设计行为：普通视频没有 Alpha 通道。无视频区间使用黑色画布；如果该区间有运动数据，数据会叠在黑色画布上。需要透明背景时请选择“透明浮层”。

13.7 天气会不会在渲染中途因断网丢失

不会。天气成功取得后随工程缓存参与渲染。风险只发生在开始导出前尚未成功载入天气时，此时软件会询问是否继续。

13.8 长视频导出失败

检查：

  • 目标磁盘剩余空间。
  • 输出目录写入权限。
  • 分辨率、帧率和码率是否过高。
  • 源视频能否被系统正常解码。
  • 调试控制台中的“导出”日志。

DataLayer Studio 按帧流式处理，不会把整段视频缓存到内存，但 4K、长时长和 ProRes 4444 仍需要足够磁盘空间。

14. 命令行使用

图形界面适合多轨编辑；命令行适合自动化和复用既有工程。

14.1 单视频与单运动文件

swift run overlay \
  --video /path/to/run.mov \
  --fit /path/to/activity.fit \
  --output /path/to/overlay.mov

常用参数：

--export-mode overlay|video
--width 1920 --height 1080
--fps 30
--codec hevc-alpha|prores-4444|hevc|h264
--bitrate 12000
--distance-unit km|m
--layout-preset "Race Layout"
--skip-fit-crc
--inspect

单源 CLI 仍支持 --fit-start、--sync-video / --sync-fit 和旧版 --offset；这些是命令行兼容能力，不代表 App 有独立同步面板。

14.2 按时间线工程导出

swift run overlay \
  --timeline-project /path/to/project.dlsproj \
  --output /path/to/output.mov \
  --export-mode video

使用 --timeline-project 时，不要再混用 --fit、--video、同步参数或布局预设。工程中的多轨结构由同一套核心渲染逻辑读取。

15. 导出前最终检查清单

  • 所有使用中的视频和运动文件都在线。
  • 视频与运动数据在至少一个明确事件上对齐。
  • FIT 暂停区间的表现符合预期。
  • 上层视频轨覆盖关系正确。
  • 运动片段使用了正确布局和距离单位。
  • 天气组件已加载完成，或确定不需要天气。
  • 数据组件没有遮住主体、字幕和安全区域。
  • 时间线内容就是要输出的内容（多余片段已删除或禁用）。
  • 尺寸、帧率、编码和码率适合目标平台。
  • 透明浮层与剪辑软件时间线从同一时刻开始。
  • 目标磁盘空间和写入权限充足。
  • 重要工程已经 ⌘S 保存。

完成这些检查后再开始长时间或 4K 输出，可以避免大多数返工。
