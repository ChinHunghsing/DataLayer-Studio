## 0. 结论摘要

macOS 版 DataLayer Studio 的渲染与导出引擎（FIT/GPX 解析、遥测插值、时间同步、布局模型、CoreGraphics 渲染、HEVC-alpha/ProRes 导出）完全没有 AppKit 依赖，全部构建在 iOS 同样提供的系统框架上，可以原样复用。做 iPad 版在技术上成立，产品上也有清晰的落点：iPad 已经形成 Final Cut Pro for iPad、LumaFusion、DaVinci Resolve for iPad 的剪辑生态，而这些剪辑器都能直接使用本应用导出的透明浮层。iPad 版的目标是**功能与 Mac 版对齐的完整编辑器**，不是精简版。

## 1. 背景与机会

macOS 版已经完成的能力：导入视频 + FIT/GPX，三种对表方式（偏移 / FIT 起点 / 打点对齐），在实时预览画布上排布 21 种数据组件（配速、心率、步频、功率、跑姿动态、天气、GPS 路线、距离进度条、时间日期等），逐组件深度定制（字体、颜色、面板、刻度、精度、缩放），布局预设保存与 iCloud 同步，导出透明 HEVC-alpha / ProRes 4444 浮层或 HEVC/H.264 合成成片，支持导出区间裁剪、码率/分辨率/帧率控制、进度与 ETA、完成通知。

做 iPad 版的三个理由：

1. **工作流迁移**：越来越多运动视频创作者在 iPad 上完成整条剪辑链（FCP iPad / LumaFusion）。浮层这一环目前必须回到 Mac，是链条断点。
2. **引擎零成本复用**：核心库约 6900 行代码不需要重写，iPad（尤其 M 系列芯片）有硬件 HEVC 编码器，导出性能与入门 Mac 相当。
3. **跨设备资产**：布局预设已经通过 iCloud Key-Value Store 同步，天然支持「Mac 上做模板、iPad 上出片」的分工。

## 2. 产品定位

一句话：**把「同步 → 排布 → 导出」的完整桌面工作流带到 iPad，成为 iPad 剪辑生态里数据浮层的供给端。**

与 Mac 版的关系：

- 能力对齐：Mac 能编辑、能导出的，iPad 都能。
- 交互重设计：菜单栏、文件面板、鼠标悬停等桌面惯例替换为 iPad 惯例（工具栏、Files/照片选择器、触控/Pencil/键盘）。
- 资产互通：布局预设经 iCloud 双向同步；导出参数、单位、语言偏好保持一致的默认值逻辑。
- 品牌一致：延续「专业、克制、可信」的深色三栏编辑器气质，原生 iPadOS 控件优先，不做网页味装饰。

### 非目标（v1 不做）

- CLI / 脚本化导出（iPad 的对应物是快捷指令 App Intents，列入远期）。
- HealthKit / Apple Watch 训练数据直接导入（列入远期，见开放问题）。
- 外接显示器的专业双屏模式（v1 只保证 Stage Manager 下布局不破）。
- 竖版 9:16 模板体系（iPhone 版主打，iPad 跟随复用）。

## 3. 目标用户

沿用既有三画像，补充 iPad 语境：

| 画像 | 描述 | iPad 侧关键诉求 |
| --- | --- | --- |
| Alex（高效老手） | 赛后当天出片，重效率与批量 | 妙控键盘全快捷键、Files 拖拽导入、预设一键套用、导出参数记忆 |
| Jordan（新手） | 第一次做数据视频 | 空状态引导、三步向导式流程、人话文案、错误可解释 |

## 4. 核心场景

1. **赛后即时出片**：比赛结束，相机视频 AirDrop 到 iPad，手表 FIT 文件从 Files 导入；打点对齐（起跑枪声帧 ↔ FIT 计时起点），套用 iCloud 里的「比赛回顾」预设，微调路线组件位置，导出透明浮层，直接在 FCP iPad 里叠上成片。
2. **通勤路上改模板**：在 Mac 上没调完的布局，iPad 上打开同一预设继续调字体和配色，存回 iCloud，回家 Mac 上直接用。
3. **教练拆解训练**：导入学员视频与 FIT，开网格与吸附，把配速/心率/步频摆成教学布局，导出合成视频发给学员。

## 6. 信息架构与布局

### 6.1 横屏（regular 宽度，主形态）

保持 Mac 的三栏心智，宽度自适应：

```
┌────────────┬──────────────────────────────┬────────────┐
│ 素材与导出    │          预览画布               │  检查器      │
│ (约 320pt)  │   （弹性，占满剩余）              │ (约 360pt)  │
│ 视频/FIT     │   视频背景 + 数据浮层            │ 选中组件设置  │
│ 对表同步     │   时间轴 + 播放控制               │ 折叠分区     │
│ 预设         │                               │ 实时值摘要   │
│ 导出设置     │                               │            │
└────────────┴──────────────────────────────┴────────────┘
```

- 左右栏均可折叠（工具栏按钮 + 快捷键），折叠后画布满屏。
- 12.9/13 英寸横屏（1366×1024pt）可三栏常驻；11 英寸横屏默认三栏，允许收起一侧。

### 6.2 竖屏与分屏（compact 宽度）

- 竖屏：画布优先。素材/导出栏与检查器变为两个可切换的底部/侧边 sheet（medium/large detent），不与画布抢空间。
- Split View / Slide Over 到 compact 宽度时同竖屏策略。编辑体验降级但完整可用，文案不隐藏功能。

### 6.3 全屏预览

沿用 Mac 的全屏预览模式：隐藏两栏，只留画布与时间轴，Esc / 按钮退出。

## 7. 关键界面

### 7.1 空状态与引导

- 首启空状态给两个大按钮：「选择视频」「选择活动文件（FIT/GPX）」，配一行说明输出可用于 FCP iPad / LumaFusion。
- 任一素材缺失时，导出按钮禁用并内联说明缺什么（延续「禁用即说明原因」原则）。

### 7.2 素材与同步（左栏）

- 视频卡片：文件名、分辨率、帧率、时长；替换按钮；支持从 Files/照片拖入。
- 活动卡片：FIT/GPX 文件名、样本数、时长；错误状态内联展示（解析失败原因）。
- 对表分区：三种模式分段选择；打点对齐模式提供「把当前预览帧设为运动开始」按钮（Mac 的 ⇧⌘S 保留为键盘快捷键）；数值输入支持帧步进微调。
- 预设分区：预设列表、套用/保存/设为默认/删除、iCloud 同步状态徽标（本地/已同步/收到更新）、JSON 导入导出走 Files。

### 7.3 预览画布

触控交互规范（重点设计对象）：

| 操作 | 手势 |
| --- | --- |
| 选中组件 | 单指点按（热区最小 44pt，小组件自动扩大热区） |
| 移动组件 | 选中后单指拖动；拖动中沿用「降采样预览」机制保证跟手 |
| 微调位置 | 检查器数值步进；硬件键盘方向键（沿用 Mac 键位）；Pencil 拖动天然更精确 |
| 缩放画布 | 双指捏合（0.25x–4x，沿用 Mac 缩放上下限）；双击空白处在「适配 ↔ 100%」间切换 |
| 平移画布 | 放大后双指拖动 |
| 组件层级 | 检查器按钮 + 键盘 ⌥⌘↑/↓ |
| 时间轴 | 底部滑杆 scrub；左右步进按钮按帧移动；空格播放/暂停（键盘） |

冲突处理：单指手势优先命中组件，未命中时落到画布（点空白取消选中）；双指手势始终属于画布。拖动组件时禁用画布平移。

### 7.4 检查器（右栏）

- 结构沿用 Mac：选中组件头部（图标、名称、显隐、复制、删除、层级）+ 折叠分区（内容/数据/外观/面板/线条/布局）+ 分区标题上的实时值摘要。
- 数值输入：触控下用「文本框 + 步进按钮」组合（替代 Mac 的滚轮/键盘步进 NSTextField），聚焦时弹数字键盘。
- 颜色：系统 ColorPicker（iPadOS 原生取色 UI，含吸管）。
- 无选中时的空状态与「隐藏组件」提示文案沿用 Mac 文案体系。

### 7.5 导出

- 参数与 Mac 完全对齐：导出模式（浮层/成片）、编码（按设备能力显示可选项）、分辨率预设+自定义、帧率预设+自定义、码率、导出区间（含快捷设置按钮）、摘要（类型/时长/目标/预估大小）。
- 导出中：进度条 + ETA + 取消；画布锁定编辑；屏幕保持常亮；显示「导出期间请保持 App 在前台」的说明（iPad 特有约束，见技术文档 §7）。
- 完成后：本地通知 + 结果卡片（在 Files 中显示 / 分享 / 存入照片（仅合成模式）/ 拷贝路径）。

### 7.6 设置

语言（四语言 + 跟随系统）、外观（深/浅/跟随系统）、单位、OpenWeather API key（钥匙串存储，输入框脱敏显示）。

## 8. 输入方式矩阵

| 能力 | 触控 | Apple Pencil | 硬件键盘 | 触控板/鼠标 |
| --- | --- | --- | --- | --- |
| 选中/拖动组件 | ✅ | ✅（悬停高亮） | — | ✅（指针悬停高亮） |
| 逐像素微调 | 步进按钮 | ✅ | 方向键（沿用 Mac 键位） | ✅ |
| 画布缩放 | 捏合 | — | ⌘+ / ⌘- / ⌘0 | 捏合/滚轮 |
| 打开视频/FIT | 按钮 | — | ⌘O / ⌘F | 按钮 |
| 导出/取消 | 按钮 | — | ⌘E / ⌘. | 按钮 |
| 播放/暂停、打点 | 按钮 | — | 空格、⇧⌘S | 按钮 |

## 9. iPad 平台能力

- **拖拽导入**：从 Files / 照片拖视频或 FIT/GPX 进窗口任意位置，落点高亮提示接收类型。
- **文档类型注册**：注册 .fit/.gpx 类型，支持从邮件、微信、Garmin Connect 分享菜单「用 DataLayer Studio 打开」。
- **多窗口**：支持多 Scene，两个项目并排（每窗口独立的编辑状态，与 Mac 每窗口一个 StudioModel 的现状一致）。
- **Stage Manager**：最小窗口尺寸下保证两栏可用，不出现截断。
- **导出完成通知**：沿用现有 UserNotifications 实现，点击通知回到 App 并定位结果卡片。

## 10. 预设与跨设备协同

- iCloud Key-Value Store 与 Mac 版使用同一存储标识，实现 Mac ↔ iPad ↔ iPhone 三端预设自动同步（前置条件见技术文档 §8）。
- 同步状态在预设分区可见：本地 / 已请求上传 / 收到 iCloud 更新（沿用 Mac 已有状态机与文案）。
- JSON 导入导出保留，作为无 iCloud 环境的兜底与备份手段。

## 11. 无障碍与本地化

- VoiceOver：画布组件已有 label/value/hint/自定义操作（Mac 版已补齐），iPad 版为验收标准之一，不允许回退。
- 键盘可达性：全部命令可通过硬件键盘触达；焦点顺序为左栏 → 画布 → 右栏。
- 动态字体：面板与检查器文案跟随动态字体（画布内渲染结果除外——它是视频产物，不随系统字号变化，需在文案中说明）。
- 本地化：任何新增文案同步 en / zh-Hans / zh-Hant / ja 四套，沿用现有 AppLocalizer 机制。

## 12. 商业化与发布

- 付费买断，与 Mac 版一致；沿用 StoreKit 2 AppTransaction 收据校验门。
- **决策点（开放问题 #1）**：iOS 版加入 Mac 版同一 App record 启用 Universal Purchase（买一次三端可用），或独立 SKU 分开定价。倾向 Universal Purchase：预设同步的价值主张就是「一套工具三端用」，分开收费会削弱它；代价是放弃 iPad 端独立营收。
- 上架物料：iPad 13 英寸与 11 英寸截图（横屏三栏 + 画布特写 + 导出页），四语言元数据，沿用 `app-store-connect` 工作流与 `yyyyMMddNN` 构建号规则。

## 15. 开放问题

1. Universal Purchase 还是独立 SKU？（影响定价与 App record 结构，需在 M2 前定）
2. 最低系统版本取 iPadOS 17 还是 18？（技术文档 §2.4 给出建议：18）
3. HealthKit / Apple Watch 训练导入是否提前到 v1.x？（免 FIT 文件搬运，对 Jordan 价值大）
4. 外接显示器全屏预览是否作为 M3 可选项？
5. iPad 版是否需要「示例项目」（内置演示视频+FIT）降低首次体验门槛？
