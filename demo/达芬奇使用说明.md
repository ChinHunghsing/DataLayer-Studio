# 在 DaVinci Resolve 中使用 DataLayer Studio 导出的视频

本文对应演示视频 `达芬奇使用演示.mov`，时间码以该视频从 `00:00` 开始计算。演示使用 DaVinci Resolve Studio 21 中文界面，其他版本的按钮位置可能略有不同。

## 使用前准备

- 在 DataLayer Studio 中完成数据同步、仪表布局和预览。
- 以带透明通道的视频格式导出叠加层。若原始视频被分成多段，应导出与各段一一对应的叠加视频。
- 准备好原始运动视频和 DataLayer Studio 导出的叠加视频。

## 操作步骤

### 1. 打开媒体池

**时间码：`00:00–00:03`**

演示开始时位于 DaVinci Resolve 的“剪辑”页面。点击左上角的“媒体池”，切换到媒体素材视图。

### 2. 导入原始视频

**时间码：`00:03–00:20`**

将需要剪辑的原始运动视频导入“主媒体夹”。演示画面在这一段等待素材完成导入和读取；导入完成后，媒体池中会显示多段原始视频缩略图。

> 演示没有显示文件选择窗口。实际操作时可将文件从 Finder 拖入媒体池，也可通过 DaVinci Resolve 的“文件 > 导入 > 媒体”选择文件。

### 3. 把原始视频放入时间线

**时间码：`00:20–00:24`**

在媒体池中选中原始视频，将它们拖到下方时间线。DaVinci Resolve 会创建 `Timeline 1`：画面进入 V1 视频轨道，原视频声音进入 A1 音频轨道。

原始视频的排列顺序应与拍摄顺序一致，后续每一段叠加视频都要与对应的原始视频对齐。

### 4. 缩放时间线并检查原始片段顺序

**时间码：`00:24–00:36`**

调整时间线缩放比例，直到能看到整条时间线。确认多段原始视频已经首尾相接，并保持正确顺序。

演示中先看到单个片段占满时间线，缩小时间线后可以看到全部原始片段。

### 5. 导入透明叠加视频

**时间码：`00:36–00:39`**

将 DataLayer Studio 导出的透明叠加视频导入同一个媒体池。演示中的叠加文件名带有 `_overlay_01.mov`、`_overlay_02.mov` 等连续编号。

透明叠加视频的缩略图大部分呈黑色是正常现象；黑色区域代表透明背景，放到原始视频上方后即可看到数据仪表。

### 6. 将第一段叠加视频放到 V2 并对齐

**时间码：`00:39–00:42`**

把 `_overlay_01.mov` 拖到 V2 视频轨道，放在第一段原始视频正上方。让叠加片段的左边缘与对应原始片段的左边缘对齐。

对齐后，预览窗口会在原始画面上显示路线、距离、配速、心率、步频、卡路里、天气和时间等数据。

### 7. 依次放置其余叠加视频

**时间码：`00:42–00:51`**

按照编号顺序，把剩余叠加视频依次拖到 V2，并与 V1 上对应的原始片段逐段对齐：

- `00:42–00:44`：放置并对齐 `_overlay_02.mov`。
- `00:44–00:46`：放置并对齐 `_overlay_03.mov`。
- `00:46–00:48`：放置并对齐 `_overlay_04.mov`。
- `00:48–00:51`：放置并对齐较长的 `_overlay_05.mov`。

每段叠加视频都应位于 V2，对应的原始视频应位于其正下方的 V1。利用时间线吸附功能，让相邻叠加片段首尾相接，并让片段边界与 V1 的剪辑点重合。

### 8. 检查叠加结果

**时间码：`00:51–01:09`**

拖动播放头或播放时间线，检查不同原始片段上的数据叠加是否连续：

- 仪表和路线应始终显示在原始画面上方。
- 切换到下一段原始视频时，对应叠加片段也应同时切换。
- 数据应随播放进度变化，不应在片段交界处出现提前、滞后或空白。
- V2 与 V1 的片段边界应保持对齐。

演示最后在时间线的多个位置移动播放头，确认路线进度、距离、配速、心率、步频、卡路里、天气和时间会随原始视频正常更新。

## 时间码速查

| 时间码 | 操作 |
| --- | --- |
| `00:00–00:03` | 打开媒体池 |
| `00:03–00:20` | 导入并等待读取原始视频 |
| `00:20–00:24` | 将原始视频放入 V1/A1 |
| `00:24–00:36` | 缩放时间线并检查片段顺序 |
| `00:36–00:39` | 导入透明叠加视频 |
| `00:39–00:42` | 将第一段叠加视频放入 V2 并对齐 |
| `00:42–00:51` | 依次放置和对齐其余叠加视频 |
| `00:51–01:09` | 移动播放头，检查完整叠加效果 |

## 常见问题

### 叠加视频放入时间线后看不到数据

确认叠加视频位于原始视频上方的 V2 或更高视频轨道，并确认对应轨道没有被禁用。不要把叠加视频放到原始视频下方。

### 叠加视频在媒体池中是黑色的

透明视频在缩略图中显示为黑色通常是正常现象。将其放到 V2 后，以预览窗口中的合成结果为准。

### 数据与画面不同步

先确认叠加片段与对应原始片段的起点完全重合。如果原始视频经过裁切，也要对叠加片段做相同的裁切并保持相同起点。

### 多段视频的叠加内容接不上

确认原始视频和叠加视频都按相同顺序排列，并检查 `_overlay_01`、`_overlay_02` 等编号是否与原始片段一一对应。
