# DataLayer Studio 0.1.1 App Store Assets

These screenshots were captured from the TestFlight build using the current saved layout preset.

- `desktop/01-source-preview.png`: video and FIT loaded with the configured telemetry overlay.
- `desktop/02-canvas-presets.png`: canvas, grid, and reusable layout preset workflow.
- `desktop/03-export-settings.png`: transparent overlay export settings.
- `datalayer-studio-preview-draft.mp4`: 15-second local preview draft. It was not uploaded to App Store Connect.

The three desktop screenshots were uploaded to App Store Connect for `en-US`, `zh-Hans`, `zh-Hant`, and `ja`.

## Framed Set

- `framed/01-hero.png`: App Store first screenshot concept using the real preview UI.
- `framed/02-live-preview.png`: framed preview workflow screenshot.
- `framed/03-layout-presets.png`: framed canvas and preset workflow screenshot.
- `framed/04-export-settings.png`: framed export settings screenshot.

The framed set validates as `APP_DESKTOP` screenshots. It was prepared after version `0.1.1` had already been submitted for review, so App Store Connect rejected replacing the submitted screenshots without canceling the current review.
