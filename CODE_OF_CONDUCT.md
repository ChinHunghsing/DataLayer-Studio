# Code of Conduct

DataLayer Studio should be a place where people can discuss video, telemetry,
Swift, FIT parsing, and design details without having to armor up first.

## Expected Behavior

- Be respectful and direct.
- Assume good intent, but accept correction quickly.
- Keep criticism focused on code, behavior, tests, design, and documentation.
- Help make issues and pull requests actionable.
- Respect that this project uses a noncommercial source-available license.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Sexualized, discriminatory, or exclusionary comments.
- Publishing someone else's private information.
- Repeatedly derailing technical discussions after being asked to stop.
- Pressuring maintainers or contributors to ignore the project license.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues or pull requests;
or restrict participation when behavior harms the project community.

If you see a problem, report it through a private GitHub security advisory when
it involves sensitive information. For ordinary conduct issues, contact a
maintainer through the repository.
