# Support

DataLayer Studio is a source-available noncommercial project. Support is
community-oriented and best-effort.

## Before Asking for Help

Please check:

- [README.md](README.md) for build, GUI, CLI, and release instructions.
- [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.
- [SECURITY.md](SECURITY.md) for vulnerabilities or private data exposure.

## Where to Ask

- Use GitHub issues for reproducible bugs and feature requests.
- Use pull requests for focused fixes or improvements.
- Do not post private videos, FIT files, GPS traces, heart-rate data, API keys,
  signing material, or local preference files in public issues or pull requests.

## Commercial Use

The public repository license is noncommercial. Commercial use, resale, paid
redistribution, paid hosting, or inclusion in a commercial product requires a
separate written commercial license from the copyright holder.
