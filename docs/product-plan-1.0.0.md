# DataLayer Studio 1.0.0 产品方案

> 方案版本：v2，2026-07-18。替代 2026-07-17 的初稿。
> 校订基线：本地 `main` 与 `origin/main` 同步；GitHub Release v1.0.0 已发布并完成下载资产验证；App Store 1.0.0（2026071803）已进入 `WAITING_FOR_REVIEW`。
> 本文只定义 1.0.0 的产品范围和发布门槛；通用开发、测试、签名与发布流程以根目录 `AGENTS.md` 为准。

## 一、修订结论

1. **保留方向**：1.0.0 是可靠性与完成度版本，不靠新增功能撑版本号。
2. **收缩范围**：取消“全 GUI 清零魔法数字”一类无边界重构，只修审计中可复现、影响用户的视觉与交互问题。
3. **纠正现状**：工程保存已经使用原子写入；1.0.0 验证并守住现状，不临时新增自动保存或崩溃恢复系统。
4. **改写验收**：编码产物不要求字节级一致；GUI 与 CLI 比较输入、时长、分辨率、帧数、水印和抽样画面。
5. **减少文档先行**：审计与修复可在同一小任务闭环，不先堆一批长期失真的清单。

## 二、版本定位

1.0.0 的承诺只有三条：

- **不丢**：已明确保存的工程可重开，旧工程与旧预设可继续使用，导出限制不会被绕过。
- **不错**：主流程无崩溃、卡死、错误结果或无反馈失败；透明 Alpha、合成导出和时间同步不回退。
- **不慢**：相同机器和素材下，候选版相对 v0.3.4 没有可解释不了的性能回退。

### Feature Freeze

1.0.0 不新增：

- 仪表类型、遥测字段、图表样式；
- 导出格式或编码器；
- 云同步、账号、社区、插件；
- iPhone 功能；iPadOS 继续独立推进，不并入也不阻塞 macOS 1.0.0；
- 自动保存、崩溃恢复等新的工程系统；
- 为“以后可能用”准备的抽象或重构。

新想法只记录到 `docs/backlog-post-1.0.md`；没有实际想法时不创建空文件。

### 红线

- 免费版继续执行 1080p 上限、`Made with DataLayer Studio` 水印和 Mac App Store 完整版购买引导；覆盖 GitHub 包、自编译 GUI 与 CLI。
- 透明 HEVC / ProRes Alpha 不得重新发灰；以 `docs/archive/qa-0.2.3-transparent-and-longform.md` 为回归基线。
- 视频写出继续逐帧流式处理，内存不得随时长线性增长。
- 旧 `.dlsproj` / `.dlspreset` 必须可加载；Codable 变更保持向后兼容。
- 用户可见文案保持英文、简体中文、繁体中文、日文四语言同步。

## 三、必做范围

### R：可靠性

| 编号 | 工作 | 验收 |
| --- | --- | --- |
| R1 | 守住工程数据 | 现有原子保存有回归测试；显式保存后强退并重开，内容完整；保存失败不覆盖旧文件 |
| R2 | 旧版本兼容 | 从 v0.2.3、v0.3.4 生成最小工程与预设 fixture，CI 验证加载与关键字段 |

| R4 | 时间线可逆性 | 移动、裁剪、分割、锁定、删除、粘贴、对表偏移的 undo/redo 成对验证；只补缺失覆盖 |

## 四、明确不做

- 不为统一外观替换所有 padding、字号、圆角和 `controlSize`。
- 不承诺“每个错误都有重试按钮”；无法在原地恢复时，清楚说明原因即可。
- 不提交大体积真实视频、FIT 或性能样本；基准只提交配置与结果，素材保留在忽略目录。
- 不要求不同编码器或不同硬件生成的文件字节级、逐帧压缩结果一致。
- 不以测试数量、文档页数或代码改动量作为完成度指标。

## 五、优先级与放行规则

| 级别 | 定义 | 1.0.0 规则 |
| --- | --- | --- |
| P0 | 数据丢失、崩溃、隐私/授权失效、透明 Alpha 或导出错误 | 必须清零 |
| P1 | 主路径阻断、明显状态错乱、严重性能回退、四语言主界面不可用 | 必须清零 |
| P2 | 不阻断任务的视觉、文案与便利性问题 | 有余量再做，未做项记录到 1.0.1 |

发现问题后直接附复现路径、证据、级别和最小验证；无需先建立独立审计项目。分级有争议时由用户裁定。
