# DataLayer Studio 简洁使用说明：导出一条数据层视频

最后更新：2026-07-07

这是一份短流程说明，模拟一次从原视频和运动数据导出透明数据层视频的过程。示例文件：

- 原视频：`run-original.mov`
- 运动数据：`run.fit` 或 `run.gpx`
- 导出结果：`run-overlay.mov`

这里的“数据层视频”指带透明 Alpha 通道的 `.mov` 浮层。导出后，把它放到剪辑软件的原视频上方轨道即可。

## 1. 导入原视频

1. 打开 DataLayer Studio。
2. 在左侧“素材”区域点击“视频”。
3. 选择 `run-original.mov`。
4. 确认中间预览区能看到视频画面。

也可以用快捷键 `⌘O` 打开视频。

## 2. 导入运动数据

1. 在左侧“素材”区域点击“运动文件”。
2. 选择 `run.fit` 或 `run.gpx`。
3. 等待状态栏提示运动文件已加载。
4. 预览区会开始显示可用的数据层。

优先使用 `.fit`。FIT 通常包含心率、步频、功率等更多数据；GPX 通常只有轨迹、时间、距离、速度或配速。

## 3. 对齐视频和运动数据

进入底部工作区的“同步”。对齐的核心是告诉软件：

> 视频里的某一个时间点 = 运动文件里的某一个运动时间点。

下面分两种常见情况。

### 情况 A：先开始运动，后开始拍摄视频

这种情况很常见：你先按下手表开始跑，过了一会儿才开始录视频。

例子：

- 手表在起跑时已经开始记录。
- 视频从运动第 `05:30` 才开始拍。
- 所以视频 `00:00` 应该对应运动 `05:30`。

操作：

1. 打开“同步”。
2. 在“视频”时间里填 `00:00.000`。
3. 在“运动”时间里填 `05:30.000`。
4. 播放视频检查路线、距离、配速是否和画面大致一致。

如果你不知道视频开头对应运动第几秒，可以找一个更清楚的匹配点：

1. 在视频里找到一个明显瞬间，例如经过路口、桥、补给点、路牌。
2. 记下这个瞬间的视频时间，例如视频 `00:18.000`。
3. 在运动记录里估算或确认同一瞬间的运动用时，例如运动 `05:48.000`。
4. 在“视频”填 `00:18.000`，在“运动”填 `05:48.000`。
5. 播放前后几秒确认数据是否对齐。

注意：这种情况下不要点击“当前画面就是运动开始”，除非当前画面真的就是运动第 `00:00`。

### 情况 B：先拍摄视频，后开始运动

这种情况也很常见：相机先开录，过一会儿你才按下手表或真正起跑。

例子：

- 视频从准备阶段开始录。
- 运动在视频第 `00:49` 才开始。
- 所以视频 `00:49` 应该对应运动 `00:00`。

推荐操作：

1. 播放或拖动时间轴，找到真正开始运动的那一帧。
2. 点击“当前画面就是运动开始”。
3. 软件会把当前视频时间对齐到运动 `00:00`。
4. 播放后续画面，确认距离、路线、配速开始变化的时机正确。

也可以手动输入：

1. 在“视频”时间里填运动开始所在的视频时间，例如 `00:49.000`。
2. 在“运动”时间里填 `00:00.000`。
3. 播放检查同步效果。

如果视频开头有很长准备画面，建议后面在“裁剪”里把导出开始点设到运动开始附近，避免数据层长时间停留在初始状态。

## 4. 简单调整数据层

1. 在预览画布上点击一个数据层。
2. 直接拖动它到合适位置。
3. 在右侧检查器里调整大小、颜色、字体或是否显示标签。
4. 如果画面太挤，只保留路线、距离、配速、心率这几个核心数据。

建议先做简单版本，不要第一次就放太多指标。观众最容易看懂的是路线、距离、配速和心率。

## 5. 设置导出范围

进入底部工作区的“裁剪”。

如果只想导出一小段：

1. 把播放头移动到想导出的开始位置。
2. 点击“当前为开始”。
3. 把播放头移动到想导出的结束位置。
4. 点击“当前为结束”。

如果要导出整段，保持“整段”即可。

## 6. 导出数据层视频

进入底部工作区的“输出”。

推荐设置：

- 导出类型：透明浮层。
- 分辨率：源视频分辨率。
- 帧率：源视频帧率。
- 编码：带透明通道的 HEVC/H.265。
- 距离单位：按需要选择公里或米。
- 目标：选择保存位置，例如 `run-overlay.mov`。

然后点击“导出浮层”。

导出完成后：

1. 打开 Final Cut Pro、DaVinci Resolve、Premiere 或其他剪辑软件。
2. 把 `run-original.mov` 放到底层轨道。
3. 把 `run-overlay.mov` 放到上方轨道。
4. 播放检查数据层是否和画面对齐。

如果你用普通播放器打开 `run-overlay.mov` 看到黑底，不一定是导出失败。很多播放器不会正确显示透明 Alpha。请放进剪辑软件上层轨道检查。

## 7. 快速检查清单

导出前确认：

- 视频已导入。
- FIT/GPX 已导入。
- 同步关系正确。
- 数据层没有遮住主体。
- 字号在手机或最终播放设备上能看清。
- 导出范围正确。
- 输出分辨率和帧率符合目标平台。

同步判断口诀：

- **视频晚于运动开始**：视频 `00:00` = 运动已经进行到的时间。
- **视频早于运动开始**：运动开始那一帧 = 运动 `00:00`。
