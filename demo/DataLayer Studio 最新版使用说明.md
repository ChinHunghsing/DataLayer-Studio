# DataLayer Studio 最新版使用说明

本文根据 `landing-page/assets/714update` 中的界面截图整理，适用于将 FIT 或 GPX 运动数据叠加到视频上的基本流程。

## 一、创建项目

启动 DataLayer Studio 后，在欢迎页选择一种开始方式：

- 点击“新建工程”，创建一个空白项目。
- 点击“打开工程…”，继续编辑已有工程。
- 也可以直接选择视频或运动文件；支持把工程、视频、FIT、GPX 文件拖入窗口。
- “最近工程”用于快速打开历史项目，“我的模板”用于从已有布局开始制作。

对应截图：`17.52.13`。

## 二、导入视频

进入编辑界面后，在左侧“素材”面板点击“导入视频…”，选择需要添加数据浮层的原始视频。导入完成后，视频会显示在素材列表和预览窗口中，并自动出现在下方时间线的 V1 轨道。

如果软件提示“继续选择运动文件？”，可以直接点击“选择运动文件”；暂时只想检查视频时，点击“稍后”。

对应截图：`17.53.09`、`17.54.38`。

## 三、导入运动数据

在“运动文件”区域点击“导入运动文件…”，选择与视频对应的 FIT 或 GPX 文件。导入完成后，运动数据会出现在素材列表和 O1 轨道中，预览画面开始显示路线、距离、配速、心率、步频、热量、天气和时间等数据浮层。

若视频与运动记录不是同时开始，可在时间线上拖动视频片段，或选中片段后在右侧“时间线片段”面板输入开始时间，使画面中的动作与运动数据对齐。拖动播放头检查不同位置，确认配速、距离和路线进度与画面一致。

对应截图：`17.54.52`、`18.23.37`。

## 四、添加和调整数据组件

切换到左侧“组件”面板，可以搜索并添加需要的数据组件。基础指标包括速度、配速、心率、步频、热量、累计爬升、距离数值等；不同运动类型还可使用步幅、功率等组件。

选中预览中的组件或右侧图层后，可进行以下调整：

- 在“格式”中修改 X、Y 位置、大小和长度，并控制组件是否显示。
- 在“内容”中设置标签、标签文字、终点标签、单位和图标等内容。
- 在“样式”中调整组件的视觉外观。
- 在“数据”中选择该组件所使用的数据字段。
- 使用图层栏中的显示、复制、上移、下移和删除按钮管理图层；“+”用于添加新图层。

可以通过播放、逐帧和缩放控件检查浮层在整段视频中的位置与可读性。

对应截图：`17.56.47`、`18.22.51`。

## 五、使用和保存模板

切换到左侧“模板”面板，可以一键应用已有模板。若当前布局需要重复使用，在“预设名称”中输入名称并点击“保存”。

- 星标模板可设为默认模板。
- “导入”和“导出”可在不同设备或项目之间迁移模板。
- 开启 iCloud 同步后，可同步个人模板。

应用模板后，仍可继续调整各组件的位置、大小、内容、样式和数据来源。

对应截图：`17.57.16`。

## 六、调整时间线

时间线中，O1 表示运动数据轨道，V1 表示视频轨道。拖动播放头可预览任意时间点；选中视频片段后，可在右侧设置片段开始时间，并查看片段时长。

导出前建议重点检查：

1. 视频片段与运动数据的开始位置是否同步。
2. 视频首尾是否都能显示正确的数据。
3. 路线进度、距离、配速和时间是否随画面连续变化。
4. 各浮层是否避开主体、字幕和画面边缘。

对应截图：`18.22.51`、`18.23.37`。

## 七、导出成片或透明浮层

点击右上角“输出”，进入导出设置。左侧可直接选择内置预设：

- 透明浮层 · ProRes 4444
- 透明浮层 · HEVC
- 合成视频 · 4K HEVC
- 合成视频 · 1080p H.264
- 竖屏视频 · 4K HEVC

随后确认分辨率、帧率、渲染范围、编码、码率、文件名和保存位置。渲染范围可选择“完整时间线”或“多个单独片段”；常用设置也可以保存为个人预设。

- 点击“导出浮层”，生成带透明通道的数据浮层文件，适合导入 DaVinci Resolve 等剪辑软件继续合成。
- 点击“导出视频”，直接生成已经叠加运动数据的成片。

导出前请查看“导出摘要”，确认分辨率、帧率、编码、时长、预计大小和目标文件均符合要求。

对应截图：`17.58.08`。

## 八、检查导出结果

打开导出文件并抽查开头、中段和结尾。成片应保留原视频画面，同时正确显示路线、距离进度、配速、心率、步频、热量、天气、运动时间、时钟和日期等信息。

如浮层过大、遮挡主体或单位不合适，返回项目调整对应组件后重新导出。

对应截图：`18.24.20`、`18.24.30`。

## 推荐的最简工作流程

新建工程 → 导入视频 → 导入 FIT/GPX → 对齐时间线 → 应用模板 → 调整组件 → 全片预览 → 选择导出预设 → 导出并检查结果。
